# M33a — Explicit cross-branch comparisons

**Development candidate only. Not released until exact-head CI, independent R2 PASS and postmerge verification.** See the [frozen charter](m33a_charter.md).

The opt-in `WorldComparison` makes two independently qualified and simulated native graph worlds comparable without creating a fake physical transition between them. Differences are always **right minus left**, at literally equal saved native SI timestamps only. For native M24a event mode with identical detector questions/policy, each event is compared using the unchanged M28b unique resolved same-direction whole-duration rule. Terminal, source-guard, unresolved, multiple-root and opposite-direction histories remain unpaired.

```python
from conductor_sim import WorldComparison, UnifiedObservationPlan, run_unified_observation_graph

# Supply a qualified original, nodes and existing question/policy.
plan = UnifiedObservationPlan(
    "m33a:lesson", original, nodes, "events", questions, policy,
    retain_source_ancestry=True,
    comparisons=(WorldComparison("two-hypotheses", "field-low", "field-high"),),
)
record = run_unified_observation_graph(plan).as_dict()
assert record["schema"] == "conductor_sim.unified_observation_graph.v3"
```

Both compared worlds retain distinct physical revision IDs and branch-local source ancestry. Siblings may separately introduce the *same* source ID as alternative hypotheses. No global retirement registry is created, and no cross-inventory energy difference is labeled work.

The comparison uses the existing M28a `_shared_rows` and M28b `_root_pair` only; it performs no new integration, temporal interpolation, browser-side dynamics, source motion, FEMM changes, 3D claim expansion or new field law. Missing physical/native worlds, incompatible modes, or no shared native timestamps are explicitly `unpaired`.

```powershell
python -m examples.m33a_cross_world --output output/m33a-cross-world.json
python -m pytest tests/test_m33a_cross_world_comparisons.py -q
```

The v3 schema is enabled **only** when `comparisons` is nonempty. Empty comparisons preserve the original M32a v1 or M32b v2 plan and result JSON shapes. Record integrity is checked against native model/observation data at result construction and again on every export, bound by the runner-issued in-process digest. This is not cryptographic authenticity of PDF source text or protection from unrestricted private Python manipulation.
