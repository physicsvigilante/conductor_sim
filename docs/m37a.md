# M37a — Ideal ground-wire current from a charge near a conducting sphere

**Development candidate; not independently reviewed or released.** Frozen scientific charter: [m37a_charter.md](m37a_charter.md), commit `89dae06df53403a8fab6743ad8bdcc10fc76c514`. Based on M36e reviewed main merge `dc347251c14e449c53d51820b4481d1bfbee2cfb`.

## The physical question M37a adds

An external point charge near a grounded solid conducting sphere induces a **net sphere charge**, which must enter/leave through the grounding terminal if the source moves. Existing M7 solves the Kelvin equilibrium, M13 computes the force and physical interaction energy, and M16a integrates the *radially moving* point charge. A static position sweep does **not** give a current unless a genuine source velocity or physical approach protocol is supplied.

For a fixed grounded solid sphere with physical radius `a`, centre `c`, a **nonzero** external point charge `q` at `x`, `d=|x-c|>a`, source velocity `v` and radial speed `v_r=v·(x-c)/d`:

\[
Q_{\rm sphere}(t)=-\frac{qa}{d(t)},\qquad
\frac{dQ_{\rm sphere}}{dt}=\frac{qa\,v_r}{d^2},\qquad
I_{\rm sphere\to ground}=-\frac{qa\,v_r}{d^2}.
\]

This is **conventional positive-charge current** in the *named direction* sphere→ground; the opposite signed ground→sphere current equals `+dQ/dt`. When `q>0` moves **inward** (`v_r<0`), the induced sphere charge becomes more negative and `I_sphere_to_ground>0`. Negative sources reverse the sign; pure tangential motion gives **zero net grounding-wire current** although the local surface charge still redistributes.

The static external source force and induced mechanical energy are from the **existing** `ExternalGroundedSphereBackend` and `force_energy` provider, not recomputed as production formulas. Independent SI checks use:

\[
F_r=-\frac{kq^2ad}{(d^2-a^2)^2},\qquad
U_{\rm mechanical}=-\frac{kq^2a}{2(d^2-a^2)},\qquad
k=(4\pi\epsilon)^{-1}.
\]

The **one-half** factor is essential for induced mechanical energy. A nonzero wire current is not the same as `dU/dt`, nor a prediction of dissipated Joule heat.

## Two deliberately distinct authoring routes

1. **Instantaneous teacher/source kinematics** (any real 3D source velocity, including tangential): `observe_grounded_sphere_wire(problem, velocity_m_s)` computes **one instant** only. Source speed and position are genuine authored inputs. It does not invent an acceleration, path, travel time, electrical wire model or time-dependent PDE. Absolute speed must be below the existing 0.1c classical cutoff.
2. **Actual elapsed-time classical radial motion:** integrate `Motion1DSpec` with the already qualified analytical `ExternalGroundedSphereBackend`, then call `observe_grounded_sphere_motion(motion)`. It attaches actual `Q(t)` and `I(t)` to every saved **M16a** position/velocity, preserving initial conditions, Newtonian force, energy drift, original sample timestamps, surface-guard status and original source identities. Each saved time slice is a newly solved static Kelvin response. To reject hand-crafted histories that satisfy local physical state checks but invent their **elapsed-time evolution**, the observer checks positions, force, energy, time, event and guard data **and re-integrates the exact M16a initial-value problem with the qualified native Kelvin backend**. The resulting history must match; this deliberate duplicate solve adds computation cost, not a new integrator or a cryptographic authenticity guarantee.

### Minimal reproducible example

```python
from conductor_sim import (
    ElectrostaticProblem, SolidSphere, Grounded, PointCharge,
    ExternalGroundedSphereBackend, Motion1DSpec, integrate_motion_1d,
    observe_grounded_sphere_wire, observe_grounded_sphere_motion,
)

problem = ElectrostaticProblem(
    (PointCharge(1e-9, (0., 0., .2)),),
    (SolidSphere(.1, Grounded(), name="Sphere A"),),
)
instant = observe_grounded_sphere_wire(problem, (0., 0., -.1))
print(instant.wire_current_sphere_to_ground_a)  # positive for +q inward

spec = Motion1DSpec(problem, 0, 1e-3, (0, 0, 1), -.05, .1, .02)
motion = integrate_motion_1d(spec, ExternalGroundedSphereBackend())
trace = observe_grounded_sphere_motion(motion)
for sample, current in zip(motion.samples, trace.observations):
    print(sample.time_s, current.induced_sphere_net_charge_c,
          current.wire_current_sphere_to_ground_a)
```

Run `python examples/grounded_sphere_wire_current.py --output output/m37a-wire.json` and verify the source-free standalone SI oracle with `python -m tools.m37a_ground_wire_reference --input output/m37a-wire.json`. The saved JSON uses separate schemas `conductor_sim.grounded_sphere_wire_instant.v1` and `conductor_sim.grounded_sphere_wire_motion.v1`. Units and current sign are explicit. The standalone stdlib SI checker validates the complete declared SI unit map and fixed conductor identity; it also checks positive finite surface clearance, all saved positions against that guard, the maximum absolute energy-drift summary and the chronology/geometry/termination consistency of saved turning and pre-contact guard events. Turning-event claims additionally require an observed outward-to-inward velocity sign change in the surrounding saved samples, with near-zero saved velocity if an event lands on an output timestamp, plus a compatible radial-distance maximum; impossible duplicate turns are rejected. These checks establish necessary local physical consistency, **not** the exact off-grid turning time or an independently integrated ODE history.
