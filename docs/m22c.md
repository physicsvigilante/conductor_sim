# M22c — Whole-rod reflection qualification for fixed-source particle motion

## JEE-focused architectural gap, not a new electrostatic formula

M22b identified a reproducible *software admission* restriction: a particle
in a physical symmetry plane could not be integrated when two identical
finite uniformly charged stationary rods lay on opposite sides of that plane.
The pre-existing `UniformRodField` provides exact 3D off-segment Coulomb
fields, and the time integrator already uses the full electric force. The
missing capability was proving symmetry of the **complete rod inventory**.
The approved acceptance was frozen before production changes in
[`m22c_charter.md`](m22c_charter.md), with a reserved case recorded separately.

`certify_rod_reflection(rods, origin_m, normal)` checks that reflection in the
physical plane preserves the full uniformly charged finite line-segment
inventory. It checks **both endpoints of each whole segment** (allowing
reversed endpoint order), exact signed total charge, equal multiplicity and
a one-to-one pairing. A segment individually fixed under reflection can be
a singleton. No charge, endpoint, force or plane is snapped or projected.

Matching coordinates must agree within a tolerance derived only from
floating-point representation (64 ulps of the local span and world
coordinates). Poorly resolved world translations are rejected. This bound
is separate from ODE relative tolerance and is not an approximate-physics
error guarantee. Ambiguous matching search is bounded to avoid pathological
combinatorics.

For a reflection-invariant collection of fixed line charges,
`V(Rp)=V(p)` and `E(Rp)=R E(p)`. For an actual point *in* the plane,
`E_normal=0`; an initially planar position/velocity therefore remains in
the invariant plane under the unchanged full-vector motion law. This proof
requires each independent source family and gravity contribution to also
preserve the plane; it is not a licence to discard transverse forces.

The previous individual-rod certification remains unchanged for already
supported in-plane rods or normal, centred rods. Ring/disc fields stay
**axis-only**, and unsymmetric fields, gravity or initial velocity are
still rejected. Source singularity guards and energy accounting are reused.

## Presentation is not a projected physical model

The M19/M21 viewer is a **physical slice** of a three-dimensional source
inventory, not a full 3D scene or off-trajectory field solution. Newly
qualified off-plane rod segments would be misleading if drawn as rods in
the physical plane simply by projecting their endpoints. For those cases
only, an opt-in `mirrored_rod_source_indices` ledger marks genuinely omitted
rod drawings, with signed endpoint normal offsets and stable physical IDs in
the visible notes. **Every omitted rod still contributes its full 3D E/V and
force** to the verified saved history. Existing individually qualified rod
views and legacy motion serializers are unchanged. The export validator
reconstructs the geometry and independently checks the omitted indices.

## Reproduce on Windows PowerShell

```powershell
git pull --ff-only
python -m pip install -e ".[test]"
python examples/mirrored_rods.py --case P1 --output output/m22c-parallel.html
python examples/mirrored_rods.py --case P2 --output output/m22c-tilted.html
Start-Process .\output\m22c-tilted.html
python -m pytest tests/test_m22c_rod_reflection.py -q
```

Both HTML files contain offline saved physical-time playback and have an
adjacent JSON source/motion/certificate record. Browser-side code does not
integrate or synthesize electrostatic fields. The reserved transfer case has
its own independently frozen JSON and separate one-time runner, executed only
after candidate freeze; its first run must be retained and any corrections
must be reported rather than called untouched transfer evidence.

## Scope and future work

This milestone changes only one reusable source-symmetry certificate, the
existing motion-plane qualifier and narrowly opt-in visual omission metadata.
It does **not** add magnetic forces, conductor response, 3D free trajectory
solving, surface-charge induction on rods, off-axis ring/disc fields, line
charge density evolution, motion of held sources or a universal graph compiler.
The solver's existing conservative source guards, energy and physical-time
contracts remain authoritative. FEMM is retained conductor nonregression,
not independent confirmation of this prescribed-rod motion physics.

Acceptance must separately state successful authoring, whole-system
qualification, completed numerical histories, actual physical checks, usable
browser playback, justified refusals and the reserved-case exposure history.
