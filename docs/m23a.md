# M23a — Reusable finite rigid-dipole investigations

M23a adds a **physical rigid pair and static observation capability**, not a
problem-specific trajectory solver. Existing `NamedSource`, `PrescribedField`
and source E/V formulas are reused. No pre-existing production file changes.
The pre-implementation acceptance and source reading are in
[m23a_charter.md](m23a_charter.md).

## Checked teaching source

`02_conductors_half_size.pdf`, physical PDF page 5, printed page 3.37, Q47:
a dipole starts parallel to a uniform electric field. Its four depicted final
directions are acute (i), perpendicular (ii), obtuse (iii), antiparallel (iv).
The problem asks for the order of potential-energy changes. No numeric angles,
charges, separation, field strength, mass or moment of inertia are given.
The checked file SHA-256 is
`9dff3c02a9f1848d2c3d99cb1a6e7a44dc7f5a51f7a3a2b8cc92d10ce1fbca5d`.
The original page was rendered and inspected, not inferred from an old audit.
This is a workbook exercise; official past-paper provenance is not claimed.

The example's q=1 nC, separation=.04 m, E=120 V/m, and 40/90/115/180 degree
representatives are **illustrative**, not transcribed numerical givens.
For this fixed uniform field, U=-p.E and delta U=pE(1-cos(theta)); hence all
four changes are positive and increase i < ii < iii < iv. The relative order
holds for any actual acute and obtuse angles as depicted, not only these choices.
Independent uniform-field reference: OpenStax University Physics Volume 2,
section 5.7, https://openstax.org/books/university-physics-volume-2/pages/5-7-electric-dipoles .

## Public authoring and observations

```python
from math import pi
from conductor_sim.dipoles import (
    RigidDipole, DipoleModel, observe_dipole, sample_orientations,
    dipole_work, uniform_rotational_equilibria, revise_dipole_model,
)
from conductor_sim.structural_scenarios import NamedSource
from conductor_sim.prescribed_fields import UniformElectricField, FixedPointField

model = DipoleModel(
    RigidDipole(charge_c=1e-9, separation_m=.04),
    (NamedSource('E:applied', 'Applied field', UniformElectricField((120.,0.,0.))),),
    model_id='lesson:dipole', provenance='Teacher illustrative values in SI',
)
observation = observe_dipole(model)
work = dipole_work(model, 0., pi/2)
angles = sample_orientations(model, tuple(i*pi/36 for i in range(73)))
child, revision = revise_dipole_model(
    model, model_id='lesson:stronger', note='Double the same applied field',
    source_changes={'E:applied': {'field_v_m': (240.,0.,0.)}},
)
```

`RigidDipole.direction` points from -q to +q. q and separation are positive;
the dipole moment is derived, never a conflicting independently entered value.
For each actual endpoint the existing external field determines its force:
F_plus=q E(r_plus), F_minus=-q E(r_minus). Net force is their vector sum;
torque is the sum of lever-arm cross force about the authored origin.
The exact finite-pair external interaction energy is q[V(r_plus)-V(r_minus)].
Only globally uniform fields use exact algebraic -p.E, also avoiding arbitrary
gauge cancellation. A nonuniform field is evaluated at BOTH endpoints; it does
not use a local p.E or p cross E approximation.

This energy excludes internal mutual binding energy. For a fixed rigid pair
that is an orientation-independent constant. Changing q or separation produces
a different model; comparing its external interaction energy is **not** the
work required to change the dipole's internal structure.

`pivot_m=None` means the centre stays fixed during an orientation investigation.
An explicit world pivot rotates BOTH endpoints and the centre about that pivot.
It is a specified static investigation constraint, not a simulated hinge.
Arbitrary poses need not be equilibria; external holding forces/torques may be
required. No mass, inertia, damping, guide force or angular velocity is invented.

`dipole_work` takes two orientations of ONE unchanged model and returns electric
and external-quasistatic endpoint work with opposite signs. It does not certify
an admissible path between endpoints. Undefined optional fields at ideal shell
surfaces do not erase finite energy/work; force and torque are null with reasons.
Singular potentials remain failures or explicit missing samples. The observer
is separate from source membership, parameter changes, equilibrium analysis and
presentation. Source-law evaluation enforces its original domain every time.

`uniform_rotational_equilibria` returns exact parallel stable and antiparallel
unstable rotational orientations, or neutral orientations at zero resultant E.
This is full-orientation rotational classification in a uniform field, not a
claim of an isolated translational equilibrium, arrival/alignment over time, or
accessibility under every chosen rotation axis. A complete nonuniform-field
root/stability search is deliberately refused, not guessed from a few samples.

## Display and transfer

`conductor_sim.dipole_viewer` provides standalone offline HTML with saved static
angle selection, actual finite endpoint positions, external force arrows, full
3D numerical vectors, torque, external energy and endpoint work. Its apparatus
is explicitly a **world xy orthographic projection**, not a physical slice;
depth is not shown and all source coordinates are available. Projected force
arrows use one common scale; the torque arc shows only the sign of tau_z, not
its magnitude or elapsed rotation. Axis-only ring/disc geometry is not drawn by
this viewer, although separately qualified numerical endpoint observations
remain available. No off-axis E/V is extrapolated.

Angular energy samples are dots, not connected paths through untested angles.
There is no Play control, browser physics, interpolation, or time value. A
complete angular history needs rotational mechanics and explicit inertia and
initial conditions, which are outside M23a.

The same observer supports the preselected **point-field** example (nonuniform
force and off-centre pivot) and **mixed-sources** example (finite charged rod,
fixed volume-charge sphere and uniform E). These are same-author-exposed teacher
hypotheticals, not blinded benchmarks. The latter has independent composite
Simpson Coulomb-line integration plus sphere and uniform-field checks. No new
production arrangement-specific path is needed. The revised-field example
uses a source-ID-preserving immutable revision and retains its parent record.
