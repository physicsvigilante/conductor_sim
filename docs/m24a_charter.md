## Reuse and intended capability
Reuse the existing qualified prescribed-source TestChargeMotionSpec / PrescribedScenario, full qE+mg observation, adaptive vector RK4 controller and source guards. The missing layer is event investigation, not a new plate/electron force law. Add typed plane-crossing and directional-velocity-reversal requests independently of the unchanged physical model. Multiple questions may be asked in one request. A terminal observation ends the reported history; it is not a contact, bounce, absorption or charge-transfer law.

Event localisation must use accepted integration intervals and fresh numerical state evaluations, not linear interpolation of saved frames. State time brackets/residuals and finite numerical resolution honestly; no rigorous global exact-ODE event-count or exact collision claims. A zero velocity component is not total rest when other components remain. Initial rest, a trajectory on a detector, grazing/tangent candidates, unresolved ordering, guard-truncated searches and no resolved event must have distinct outcomes. Do not infer absence/uniqueness from a coarse output grid. No source guard may be relaxed or reclassified as contact.

Scope: existing prescribed fixed-source planar/axial particle motion and uniform gravity; infinite passive observation planes / explicitly labelled terminal stop surfaces. Conductor-induced force models, finite patches, singular-surface impact, dipole angular events and post-impact laws remain outside this first event service. Reuse the integrator through a narrowly opt-in accepted-step monitor if necessary; legacy executions and schemas must retain their behaviour. No universal callback registry or independent per-problem integrator.
