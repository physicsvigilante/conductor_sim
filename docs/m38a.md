# M38a — Prescribed 3D line near a grounded solid sphere (development)

**Scope and source:** This is a teacher-authored **off-axis extension** of the apparatus in the existing, separately reviewed workbook p8 Multiple Correct Q21. The printed question has a charge approaching *radially* at an externally maintained constant small speed. **M37b**, not M38a, is the faithful original-question replay. This milestone must not inflate the provisional 30-question cohort or claim a second solved JEE problem.

## Why this is new and reusable

M37a already certifies the instantaneous grounded-sphere Kelvin observation for an actual source position and velocity; M37b already certifies radial constant-speed time histories and a source-specific browser viewer. M38a authors a **physically straight Cartesian line in any 3D direction**, including a closest passage **between** sampled frames. A fixed vector velocity need not have a constant radial component relative to the sphere: the charge approaches, momentarily passes tangentially and recedes without changing its Cartesian velocity. The **signed conventional net ground-wire current** goes from positive to zero to negative for a positive source, although local induced surface charge can redistribute at every instant.

The new PrescribedSphereLineSpec holds one immutable original ElectrostaticProblem, a constant 3-vector SI velocity, a real prescribed duration, a bounded sample count and a strictly positive surface guard. It accepts exactly one nonzero external PointCharge, one physically solid SolidSphere(Grounded()) and one homogeneous medium. There is no new force law: for **each genuinely authored physical time** it makes a new point-charge placement and invokes the unchanged observe_grounded_sphere_wire, which uses M7 Kelvin native charge, M13 native force/energy and M37a's signed charge derivative. Both terminal directions are stored.

The real continuous line segment is checked **before** execution by solving its exact closest-approach quadratic. It is not enough for sampled frames to look safe: a segment that crosses the metal or surface guard between frames must be refused. A small numerical resolution margin makes near-tangent approval conservative. This is a kinematic safety proof for an **exactly linear** supplied path, not a general bound for arbitrary splines, or a new collision/integration model.

## Reproduce a real teacher-authored 3D example

~~~sh
python -m pip install -e ".[test]"
python -m pytest tests/test_m38a_prescribed_line.py -q
python examples/m38a_line_approach.py --output output/m38a/teacher-off-axis-line.json
python -m tools.m38a_line_reference --input output/m38a/teacher-off-axis-line.json --output output/m38a/independent-reference.json
~~~

The example has q=+1 nC, solid grounded radius a=0.1 m, x0=(-0.4,0.2,0) m and **constant Cartesian v=(+0.2,0,0) m/s** for four prescribed seconds. A genuine closest approach occurs at t=2 s, d=0.2 m (strictly above a+0.01 m guard). Each of 41 time states has an independently solved Kelvin induced net Q, positive sphere-to-ground current on approach, zero net wire current at closest approach, negative current after, genuine induced force and interaction energy.

The new JSON conductor_sim.prescribed_ground_line.v1 distinguishes constant Cartesian velocity from *changing* radial speed, includes every signed physical observation and retains source/teacher provenance. Its as_dict() re-executes the actual typed physical history before accepting the saved rows, so a substituted Boolean zero, altered time, charge, current or force cannot be exported as native truth. This is **in-process** checking, not a cryptographic signature or independent solver proof.

The separate **standard-library-only** tools.m38a_line_reference does not import conductor_sim. It analytically recomputes the full line, closest approach, all 41 independent Kelvin Q/current/force/energy values, original-source-versus-teacher claims and exact SI units. Its derivative is I_sphere_to_ground = -q*a*(r.v)/|r|^3; at an instantaneous tangent (r.v)=0 the **net** ideal ground current is zero. The standalone checker independently rejects wrong current signs, underresolved geometry, a false physical duration, invalid provenance, Boolean timestamps and continuous paths that intersect the metal between frames. The native test suite also differentiates newly solved static sphere charges around a saved time, rather than comparing one produced current to itself.

## Limits and acceptance

This is an externally maintained straight path with an unspecified outside actuator, *not* a Newtonian free orbit or a charge moving under its own Kelvin force. Only one grounded solid sphere, one point source, quasi-static perfect equilibration and nonrelativistic motion are qualified. There is no claimed transient FEMM, electric conduction mechanism inside the ground wire, radiation, finite wave propagation, resistance/heat, collision, arbitrary spline or unqualified off-axis FEMM solver. A 3D Cartesian point can be plotted later without claiming that a radial M37b diagram depicts it faithfully.

**No new viewer in M38a.** The existing source-fidelity Chromium viewer remains unmodified. Plan any off-axis 2D/3D path and synchronized graph as a separate **M38b** milestone with its own no-JavaScript first-frame scrutiny; do not retrofit wrong geometry into the original-source radial figure.
