## Acceptance and evidence gates

1. A standalone Python **runner** calls the existing public/released source models and genuine numerical/observer services; it does not hardcode answer trajectories or forge sample objects. Preserve source IDs/givens and explicitly label illustrative inputs. Save exact native event/sample values and *real* derived/static observer values, with JSON finite numbers only.
2. A **separate standard-library-only reference checker** must import no `conductor_sim` or example modules. It consumes saved native observations but derives expected magnitudes from literal original source givens and independent Coulomb/Newton reference formulas, checking timestamps, signs, energy/geometry, start/end and source masking. Cross-case results cannot be certified solely by comparing one production field callback to another.
3. Produce offline HTML views using existing renderer for all seven permitted cases and run real offline Chromium opening/meaningful label/content checks and screenshots. Browser tests cannot substitute for numerical physics. The refusal is not rendered as fake geometry.
4. Include negative tamper controls (e.g. reversed sheet sign, fake dipole time dynamics, loss of transverse ring field, forged event time, false 2021 contour, a multicavity support PASS), source-provenance checks and independent test failures preserved.
5. Publish a case-by-case report with **five distinct educational axes**, standalone denominator `7 actual supported apparatus tried`, separately `1 justified refusal`, independently physically verified vs failed, educationally inspected vs uninspected, and optional answer completeness; no `N/30` solved statement. Preserve M36a's historical 30 provisional inventory and all original PDFs.
6. No new physics law, arbitrary 3D FEMM solver, automatic PDF parser, general scene graph or modifying source-given numerical facts. Build only a bounded evaluation/observer adapter; if actual existing source code fails, add a distinct correction with source-pin and independent review rather than faking observed outputs.
7. Keep implementation PR **draft** until its actual source CI and new source-pinned replay+Chromium workflow pass and a separate R2 reviewer completes original out-of-sample physics/refusal probes. Owner explicitly approves exact-head merge; release only after verified main tree and all postmerge checks.

**Stop condition:** An honest failure or refusal is a meaningful result. Do not replace a preregistered case or silently treat a visual mockup as a solved physical question.
