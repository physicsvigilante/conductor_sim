## Minimal qualified implementation

`MixedRadialBackend` now admits a **single** `SolidSphere` as well as its original one-solid-plus-1–7-concentric-shell domain. It reuses its already qualified `MixedRadialSolution`, exact Gaussian radial formulas and the existing M5 geometry/scene renderer. The only physical code change is the admission threshold for one solid; no new solver class, numerical integrator, FEMM geometry or broad authoring architecture.

The currently qualified models:
- One standalone isolated `SolidSphere(R, FixedNetCharge(Q), name="Sphere A")`, positive, negative or zero signed charge.
- One standalone `SolidSphere(R, Grounded(), name="Sphere A")` in charge-free space: true `V=0, Q=0, E=0`.
- A real revised teacher model with stable physical ID and changed `R,Q`, even a shifted world center, subject to the same static source admission.

**Not qualified:** external or internal point sources, conductor response to nearby charges, multiple nonconcentric or overlapping standalone solids, dielectric boundaries, arbitrary 3D irregular metal, charge-motion or current-time effects. Historical one solid plus multiple real shells is unchanged. Existing M6 historical `pdf_benchmark` case is unchanged and remains the old hollow shell baseline; this is a distinct **source-authentic p26 demonstration**.

### Independent Gauss-law physical reference

For charge `Q`, radius `R`, center `c` and `k=1/(4π ε)`:

[
V(r)=\begin{cases}kQ/R&r\le R\\kQ/r&r>R\end{cases},
\qquad
\mathbf E(r)=\begin{cases}\mathbf0&r<R\\kQ(\mathbf x-\mathbf c)/r^3&r>R\end{cases},
\qquad
\sigma_{\mathrm{outer}}=Q/(4\pi R^2),
\quad r=|\mathbf x-\mathbf c|.
]

The ideal jump of `E` at the metal boundary `r=R` has **two one-sided limits** and is refused as a single-valued field sample. There is **no physical inner surface**: the existing `ConductorResult.inner_surface_charge_c=0` is a bookkeeping zero, not a false hollow cavity.

The independent source-free checker also derives `U_{\mathrm{exterior}}=kQ^2/(2R)` as a reference electrostatic self-energy. **No measured native energy or wire-heat release is claimed.**
