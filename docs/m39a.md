## Reusable qualified authoring contract

The new conductor_sim.cavity_gauss module has four core immutable types: CavityCharge(source_id,charge_c), SealedCavity(cavity_id,sources), GaussCavityAssembly(conductor_id,cavities,constraint,epsilon), and GaussCavityLedger returned by solve_cavity_gauss. An assembly declares ONE bounded, finite, single connected metal body containing 1–8 sealed, mutually noncontacting cavities and at most 16 named sources. Each source ID belongs to exactly one cavity. The electrical constraint is either FixedNetCharge on an isolated metal or Grounded at zero potential; homogeneous positive permittivity is required. No external source, applied field, electrodes, other conductor, wire physics or time evolution is modeled.

**The membership is declared, not geometrically verified.** There are no coordinates, cavity shapes, surface areas or meshes. A teacher must explicitly state which source is inside which closed void. This is NOT a full ElectrostaticProblem/FieldSolution and the engine will not infer a physically shaped cavity from this topology-only declaration.

For enclosed source sum q_i in cavity i and combined source charge S, the mathematical conductor-Gauss identities are:

- **Each complete inner face:** Q_inner_i = -q_i
- **Isolated conductor:** outer-face Q_outer = Q_metal + S; exterior electric flux Phi_E = Q_outer / epsilon
- **Grounded, no external charges/field, V=0 at infinity:** Q_outer = 0; equilibrium net Q_metal = -S; exterior E=0 by uniqueness

The last field-zero statement is only a theorem for a fully grounded **whole connected conductor exterior**, not a point-field solution. No local cavity electric field, surface charge density or exterior isolated-body E(x) is computed. The grounded record cannot infer a charge *transferred* to Earth without an authored initial state. Two separate static models are not a wire-current waveform.

Scientific context: [OpenStax University Physics 2 section 6.4](https://openstax.org/books/university-physics-volume-2/pages/6-4-conductors-in-electrostatic-equilibrium), and [Pathak arXiv:1609.04248](https://arxiv.org/abs/1609.04248) for the cavity/exterior uniqueness property. Neither independently certifies a nonexistent geometry solver.

- Cavity B: −1 nC inside; inner-face +1 nC

## Independent scientific and data integrity

The standalone standard-library-only tools/m39a_gauss_reference imports NO production physics. It reconstructs every cavity/source identity, derives signed Gauss totals with order-invariant exact rational arithmetic on admitted binary64 inputs, and checks strict Boolean/zero/sign integrity, topology/provenance/units and refusal flags. Nonzero exterior flux too small for binary64 is refused, not exported as exact zero. Self-consistently rewritten JSON IDs cannot be authenticated without an external trusted manifest. Native export re-executes the complete typed assembly and rejects forged saved face/current/charge data rather than silently repairing it. Such in-process validation plus independent arithmetic is NOT a cryptographic assertion that an arbitrary externally authored JSON has authentic historical provenance.

Invalid source types, duplicate IDs or cavity membership, impossible finite SI arithmetic, Boolean values, unsupported constraints, unknown geometrical or temporal extensions are refused. Field/force/current and local surface-charge-density methods clearly raise unsupported-domain errors rather than extrapolate a concentric or Kelvin field into an arbitrary sealed cavity.
