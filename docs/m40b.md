# M40b — Actual spherical-cavity source geometry and local sigma atlas (DRAFT)

**Status:** draft implementation candidate on [PR #102](https://github.com/physicsvigilante/conductor_sim/pull/102); **NOT yet independent reviewer approved or released**. Frozen prior charter: [M40b charter](m40b_charter.md), issue [#101](https://github.com/physicsvigilante/conductor_sim/issues/101).

This is a teaching presentation over **released M40a qualified physics** — not a new numerical solver, new JEE answer engine, or general 3D field simulation.

## What is actually visible

A real bounded, connected spherical metal contains 1–8 mutually disjoint genuinely spherical sealed cavities with 3D positions and named fixed charges. The offline SVG displays their **physical XY orthographic projection** on a single metre scale. Every source and cavity lists full X,Y,Z coordinates; **projected overlapping circles may be disjoint in 3D**. The projection is not a cross-section solution or proof of cavity intersection, and there are no invented field lines, potentials, forces or current arrows.

Every cavity also gets a **discrete 4-by-6 atlas** of 24 point samples across actual spherical rays. Each signed C/m² number comes from a fresh M40a `inner_surface_charge_density` query; the angles θ (measured from +z) and φ (from +x toward +y) are approximate labels, and the original binary64 `input_direction` remains the precise physical ray for near-wall calculations. Colored tiles indicate **sign only**, not magnitude or area-mean. No interpolated continuous field or inferred surface integral is displayed.

The whole-face M39a Gauss charge in C is shown separately and is **not** computed from the 24 atlas points. A signed-neutral cavity may have both positive and negative local density, while its whole-face total remains exactly zero. An empty cavity has zero local density. Separate **isolated versus grounded static equilibria** share exactly the same geometry, source IDs/charges and inner-wall σ; the uniform spherical outer σ follows the respective true Gauss total. This is **not a grounding-current time history**.

All teacher scenario values are illustrative. **Zero new original scanned JEE workbook questions have been solved.** Irregular cavities, arbitrary local E(x), V(x), moving charges, forces, finite-resistance wires and other conductors remain unsupported.

## Generate the actual physical HTML and evidence

From the repository checkout (including this draft PR):

```sh
python -m pip install -e ".[test]"
python -m pytest tests/test_m40b_spherical_atlas.py -q
python -m tools.m40b_spherical_atlas_example --output-dir output/m40b
python -m tools.m40b_spherical_atlas_reference --input output/m40b/m40b-teacher-atlas.json --output output/m40b/independent-witness.json
```

Open `output/m40b/m40b-teacher-atlas.html` in a browser. It has no JavaScript dependency, web requests, assets or client-side physics. Signed SI values, true XYZ source coordinates and all 24 atlas values per cavity must remain visible with JavaScript disabled and on narrow screens (horizontally scrollable rows). The native renderer accepts only real, freshly verified M40a solution objects, *never* externally supplied arbitrary JSON.

The versioned `m40b-teacher-atlas.json` records both actual M40a v2 per-face native witness exports. The separate stdlib verifier `tools.m40b_spherical_atlas_reference` imports **no conductor_sim physics**: it rechecks each source-and-geometry record using its prior independent **real charge plus Kelvin image normal electric field** and checks every displayed number, source identity, θ/φ display angle, pair property, SI claim and explicit refusal flag against the same exported evidence. This is **internal scientific consistency**, not cryptographic proof of a self-consistent external file's historical teacher provenance without a separate trusted anchor.
