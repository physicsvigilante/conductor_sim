# M32b — Certified source ancestry across mixed-order physical-world graphs

**Development candidate, not a released feature until independent R2 review.**
See [frozen preimplementation M32b charter](m32b_charter.md).

M32a already lets a teacher compose *structural then physical* worlds but
deliberately refused adding/replacing/removing a held source AFTER an ordinary
M20b physical revision: the latter turns a native M22a
`ScenarioReassembly` ancestry into a plain `PrescribedScenario`. The missing
retired-source history could permit an earlier source ID to be reused.
M32b supplies one reusable immutable `SourceWorldAncestry` certificate per
admitted world, preserving the **branch-local complete ID history** even
across genuine M20b physical-property edits.

For backward compatibility, the new behavior is explicitly **opt-in**:

```python
# Given an existing native M32a UnifiedObservationPlan:
#   legacy_plan = UnifiedObservationPlan(...)  # old M32a v1
# New mixed-order graph adds retain_source_ancestry=True:
plan = UnifiedObservationPlan(
    "m32b:mix", original,
    (
        StructuralWorldNode("add-E", "baseline", add_case, "events"),
        PhysicalWorldNode("source-mass", "add-E", "Atomic physical edit",
            (CoupledPropertyEdit("field:Enew", "field_v_m", (150.,0.,0.)),
             CoupledPropertyEdit("test-particle", "mass_kg", 2e-5)),
            "events"),
        StructuralWorldNode("replace-after", "source-mass", replacement_case, "events"),
    ),
    "events", questions, event_policy,
    retain_source_ancestry=True,
)
result = run_unified_observation_graph(plan)
evidence = result.as_dict()  # v2 native-only detached record, NOT an imported model
```

When this flag is omitted (its default is `False`), M32a's original
structural-after-physical refusal and **byte-shape-compatible v1 graph JSON**
remain unchanged. When enabled, `conductor_sim.unified_observation_graph.v2`
includes a v2 plan, a certified original graph root and exact per-world
parent/child `conductor_sim.source_world_ancestry.v1` records.

Every certificate binds actual model revision hashes and immediate parent
world, a sequence of actual visited world IDs and revision IDs, original
and introduced named held-source IDs, currently active IDs, **EVER used** IDs,
and now-retired IDs. Structural operations are checked against the entire
ancestral ID history before invoking unchanged M22a `reassemble_scenario`;
any attempted resurrection of an earlier retired ID refuses. M20b physical
revisions preserve membership exactly but transfer the complete certificate
to their child, so an intervening physical edit can no longer erase earlier
retired-ID evidence. The M22a reassembly still uses the actual immediate
physical `PrescribedScenario`, never a substituted old model. Graph branches
are independent teacher hypotheses; no global ID registry is invented.

The source certificate begins at the **supplied original graph-root model**.
An earlier unprovided retirement history before that root cannot be known
or authenticated from a bare native `PrescribedScenario`. Likewise, an
author-asserted source-given PDF transcription is not cryptographically or
textbook authenticated by this system.

After every admitted world, the engine still runs genuine unchanged
M19/M27 particle motion or M24a typed event integration. Event-study refusal
on a physically admitted parent may still allow a separately qualified
structural child; physically refused worlds never generate native motion.
Actual same-mode saved SI times and duration-complete unique same-direction
root pairing use unchanged M28a/M28b rules. True source guards and
terminal/unresolved histories do not produce fabricated later events.

Result construction and detached JSON export independently recheck all
certificates against the actual native parent worlds and bind them to the
runner-issued in-process evidence receipt alongside physical authoring and
native observations. It is an ordinary typed-result integrity boundary,
NOT cryptographic security against unrestricted private-Python manipulation,
and not an exact ODE error theorem.


This milestone changes **no** field/force laws, numerical RK, M24a event
locator, conductor FEMM equilibrium, collision/contact or source-motion
physics. It is a composability and source-provenance improvement; no new
scene graph, responding conductor, unrestricted 3D or browser-time solver.
