# M23b — Composable fixed-axis dipole dynamics

## Physical capability, not a special question solver

The new `DipoleMotionSpec` composes an unchanged M23a finite `DipoleModel`
with a physical **fixed ideal hinge**, a unit rotation axis, an explicit
constant moment of inertia about that axis, and actual initial angular state.
The same integrator handles uniform-field libration, complete rotations,
nonuniform point-source fields and mixed existing source inventories.

All examples are teacher hypotheticals. Workbook p5 Q47 remains an
independent static energy-ranking investigation: its statement supplies no
moment of inertia or angular initial conditions. M23b does not infer those
facts or describe its motion as an official past-paper reproduction.

For the actual pivot and axis n, the scalar equation is

    I * theta'' = n . sum((r_endpoint - pivot) cross F_endpoint)
    F_plus = q E(r_plus); F_minus = -q E(r_minus)
    K = I omega^2 / 2
    H = K + U_external

Existing `orient_dipole` and `observe_dipole` evaluate the real rotated
endpoints and finite-pair energy, including the motion of an off-centre
dipole centre. The full torque and force vectors are retained, even when
only the axial torque drives the constrained degree of freedom. This is
NOT an unqualified projection of free rigid-body dynamics. The ideal
frictionless support may react other forces/torques without doing work;
support reactions cannot be determined here without full mass distribution.

I is the body's moment of inertia about the ACTUAL authored axis, including
an off-centre carrier if present, not automatically a centre-of-mass value.
No endpoint masses, gravity on an unspecified mass distribution, inertia,
damping, polarization, field switching or source response are invented.
Fixed-length mutual binding energy remains an excluded constant.

Reference mechanics: OpenStax University Physics Volume 1, sections 10.4,
10.7 and 10.8 (fixed-axis inertia, angular dynamics and work):
https://openstax.org/books/university-physics-volume-1/pages/10-7-newtons-second-law-for-rotation
Uniform electric-dipole torque reference:
https://openstax.org/books/university-physics-volume-2/pages/5-7-electric-dipoles
Nonuniform external fields use exact finite endpoint observations, NOT the
uniform-field point-dipole approximation.

## Reuse and bounded new numerical work

The existing dimension-independent `_motion_rk4.rk4_step` and
`_motion_time.output_times` are reused unchanged. The two-state angular
controller is separate from the translational controller's mass, length and
velocity semantics; no artificial equivalent particle is introduced.

Step doubling estimates local error. The default policy is 2e-10: a
dimensionless one-radian angular scale and relative angular-velocity scale
(at least 1 rad/s) with 1e-12 absolute floors. Angular tolerance does not
loosen as the unwrapped revolution count grows. Output times are exact
requested saved values; a residual smaller than eight time ulps is rounded
to the requested target rather than causing false step collapse.
A finite internal-step budget, angle-resolution checks and the existing
nonrelativistic 0.1c endpoint-speed boundary are explicit failure conditions.

Source guards use the unchanged built-in clearance laws for point sources,
finite rods and ideal shell surfaces. A smooth volume-charge sphere remains
mechanically transparent as in its existing model. A conservative check
covers the **entire numerical swept angular interval**: a midpoint
clearance minus maximum endpoint rotation radius times half-angle bounds
all clearances. Inconclusive intervals subdivide; they are never accepted
by default. A full revolution cannot skip a singular source merely because
its start and end positions agree. RK stages are checked as well.

This is a conservative numerical approach policy, not an exact contact
solver, collision law or a rigorous global error enclosure of the true ODE.
The guard cutoff stops outside the singular set/field jump. The connector
between charges is an ideal rigid constraint; it is not a separately
collision-modelled material rod. Source response and steric interactions
are outside this fixed-field regime.

Axis-only ring/disc sources are rejected for rotational dynamics. The
static M23a observer may still answer separately qualified endpoint
questions; finite endpoint potential is not permission for a dynamic
crossing through an undefined field.

## Public authoring example

```python
from conductor_sim.dipoles import RigidDipole, DipoleModel
from conductor_sim.structural_scenarios import NamedSource
from conductor_sim.prescribed_fields import UniformElectricField
from conductor_sim.dipole_motion import (
    DipoleMotionSpec, integrate_dipole_motion, revise_dipole_motion,
)
from conductor_sim.dipole_motion_viewer import write_dipole_motion

model = DipoleModel(
    RigidDipole(1e-9, .04, pivot_m=(0., 0., 0.)),
    (NamedSource("field:E", "Applied E", UniformElectricField((120., 0., 0.))),),
    model_id="teacher:dipole",
    provenance="Teacher hypothetical; SI values and ideal fixed hinge.",
)
spec = DipoleMotionSpec(
    model=model, rotation_axis=(0., 0., 1.), inertia_kg_m2=4.8e-11,
    initial_angle_rad=.1, initial_angular_velocity_rad_s=0.,
    duration_s=1.5, sample_interval_s=.01,
)
result = integrate_dipole_motion(spec)
write_dipole_motion(result, "output/angular.html")
child, change = revise_dipole_motion(
    spec, note="Teacher doubles moment of inertia about the same axis",
    inertia_kg_m2=9.6e-11,
)
```

Model source-property revisions use M23a's `revise_dipole_model`, followed
by a new/revised motion request and full qualification. Initial angle,
angular velocity and inertia are genuine physical edits, not solver initial
guesses. The original model and request remain unchanged. Changing numerical
policy is a new numerical request, not disguised as a physical revision.

## Preselected acceptance and independent evidence

The charter was committed before implementation at
`044a3bc169123c741a96774df86d5502d7c26670`.

| Case | Physics observation |
| --- | --- |
| `small-oscillation` | Uniform E=120 V/m, q=1 nC, length=.04 m, I=4.8e-11 kg m^2; theta0=.1, omega0=0. Independent small-angle omega0=10 rad/s and nonlinear energy-quadrature period. |
| `libration` | Same model, omega_initial=15 rad/s from theta=0, below the 20 rad/s energy threshold; reversals are real numerical motion. |
| `rotation` | Same model, omega_initial=25 rad/s, above threshold; unwrapped angles retain complete revolutions. |
| `point-pivot` | Held Q=2 nC at (.12,.06,0) m, fixed pivot (-.015,0,0) m. Independent endpoint Coulomb torque, energy and velocity-Verlet integration. |
| `mixed-sources` | Held finite rod + fixed volume-charge sphere + uniform E; same production path. Independent rod quadrature checks full torque/energy. |
| `source-guard` | A real approach to a held point source ends outside the numerical guard, with an honest truncated time history. |

These are exposed, same-developer cases, not a blinded or independent-LLM
authoring benchmark. Reuse is assessed separately from independent physical
references and visual acceptance. The local additional DOP853 reference
uses an independent scalar pendulum/Coulomb RHS; SciPy is not a new runtime
or CI dependency. Its logs and version belong in the retained evidence.

Negative/control cases cover malformed/missing inertia/axis/pivot, zero
field, exact equilibrium, full-angle hidden guard crossings, unequal
physical/numerical policies, source limits, 3D covariance, reverse axis,
step exhaustion, nonrelativistic limits, saved-data tampering and preserved
initial state. No source qualifier or historical solver is relaxed.

## Offline viewer and limits of observations

The new time player selects **saved physical times** with play/pause/reset,
scrub and physical-time speed control. No browser ODE or interpolated
rotation is presented as simulation. It displays unwrapped angle, angular
velocity, acceleration, full endpoint forces, axial/full torque, K, U and
total energy. One spatial and force scale is retained across each run.

Apparatus drawings are labelled world xy orthographic projections, not
physical slices. Depth and any force components perpendicular to the
screen remain in the full numeric readout. The purple torque arc indicates
only projected axial handedness, not torque magnitude or angular velocity.

Sign changes of saved angular velocity are reported as **time brackets**,
not exact turning events. Guard-truncated results are not complete-duration
runs. The existing M23a angle slider remains static, with unchanged bytes.
