# M22a — Qualified structural reassembly: predeclared acceptance

Approved base: `2f306433f84f8259b5796719a18ecba9239a5841` (M21e).
This charter is committed before implementation or evaluation. It is a curated
JEE-relevant developer authoring trial, not a blind exam benchmark.

## Bounded objective

Add a separate, opt-in structural-reassembly operation for the existing
`PrescribedScenario` family: add/remove supported named fixed sources,
explicitly replace a source with a new identity, and explicitly add/remove
uniform gravity. Reuse the existing whole-system qualification, integration,
parameter revision and standalone viewers. No new electrostatic law,
integrator, numerical defaults, symmetry tolerance, conductor geometry,
neutral-particle API, arbitrary callback or universal graph compiler.

All structural edits are assembled atomically before qualification. Preserve
the parent, unchanged source identities and source order. Replacement must
not silently assign a different physical meaning to an existing identity.
A separate immutable structural record must bind the actual parent and child,
record actual component inventories, and label the child teacher-hypothetical.
Old parameter-revision records, schemas, hashes and comparison refusals are
unchanged. Structurally different inventories are not silently admitted to
M20a's parameter-only paired viewer. Requested observations are separate from
physical admissibility and numerical completion.

## Preselected positive and transfer cards

| Card | Reassembly / teaching purpose | Independent check |
|---|---|---|
| P1 | Add a second fixed point charge to a charged-particle baseline | Direct Coulomb superposition; energy |
| P2 | Add uniform E and gravity together to a zero-E launch model | Exact constant-acceleration motion; separate force/energy terms |
| P3 | Add a coaxial charged ring to an axial-ring model | Sum of analytical axial ring fields/potentials |
| U1 | Author three signed point sources at noncollinear in-plane positions through reassembly | Direct signed Coulomb field/potential; complete 2D history |
| U2 | Compose a finite fixed rod, held point charge and uniform gravity | Independent rod quadrature, point field and gravity; energy |
| U3 | Compose three coaxial rings, an axial uniform E and collinear gravity | Independent axial formulas and force ledger |
| R1 | Replace a held point source by a fixed uniform volume sphere under a NEW ID | Interior/exterior sphere reference; explicit replacement ledger |
| R2 | Remove a named source and gravity from a previously assembled model | Remaining-source field, parent purity and lineage |
| A1 | Atomically add both members of an off-slice mirrored point pair | Existing M21c certificate; no intermediate model admitted |

All transfer arrangements use existing public authoring, force and motion
interfaces after the one shared API is implemented. No per-card production
branch/callback/solver or changed numerical tolerance is allowed. Numeric
example choices are teacher hypotheticals in SI, not asserted exam givens.

## Preselected negative / boundary cards

- N1: off-axis ring or incompatible gravity direction: qualification refusal.
- N2: remove just one member of a mirrored off-slice pair: symmetry refusal.
- N3: insert a conducting object or custom source subclass: unsupported regime.
- N4: duplicate, unknown, reserved or reused replacement identities: explicit refusal.
- N5: source singularity/guard at initial position and source-count overflow:
  existing numerical/domain contract refusal, not weakened by reassembly.
- N6: compare structurally different source/gravity inventories using M20a:
  physical models may be valid, but the old paired-comparison contract refuses.
- N7: invalid edit leaves the original model, hashes and all source objects intact.

## Permanent evaluation and acceptance

Adopt a prospective composability contract distinguishing fresh assembly,
structural revision, qualification, solving, investigations, hypotheses and
observations/presentation. Preserve the existing teaching-accompaniment rubric:
interpretation, physical correctness, coverage, usefulness and optional
textbook-answer completeness are separately evaluated. Existing signed/frozen
and historical evidence is never rewritten or rescored.

Automate the preselected cards with separate authoring, qualification,
numerical-completion, physical-reference and observation outcomes. Correct
refusals are not counted as successful simulations. Record denominators and
reasons; do not convert curated coverage into JEE frequency statistics.
Require independent numerical references, immutable actual-change lineage,
legacy characterization, existing Python/FEMM nonregression and a few actual
offline Chromium standalone views using existing rendering code. No new
production physics is permitted to make an unfamiliar card pass; report gaps.
