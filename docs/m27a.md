# M27a — Static off-axis field and potential of fixed uniformly charged rings

**Milestone:** one new electrostatic source law and an opt-in static observer,
not a new particle integrator, conductor model, or general scene graph.
Preimplementation acceptance: [frozen charter](m27a_charter.md).

## Physics

`UniformRingField(Q, a, center_m=(...), axis=(...))` represents an
infinitesimally thin, stationary **nonconducting** uniformly charged circular
ring with total signed charge `Q` and true 3D orientation. It is independent
of the moving test charge and does not redistribute its charge in response
to other fixed sources. Values are SI, with the `PrescribedField`
homogeneous permittivity and linear superposition contracts.

Let `rho` be distance from the ring's symmetry axis, `z` signed axial
distance, `a` ring radius, `b²=(a+rho)²+z²`, `d²=(a-rho)²+z²`,
`m=4*a*rho/b²`, and `k=1/(4*pi*epsilon)`. For off-axis non-wire points,
the genuine exact complete-elliptic formulas are

```text
V      = (2*k*Q/(pi*b)) * K(m)
E_z    = (2*k*Q*z/(pi*b*d²)) * E(m)
E_rho  = (k*Q/(pi*rho*b)) * [K(m) + ((rho²-a²-z²)/d²)*E(m)]
E      = E_z * axis + E_rho * unit(radial_displacement)
```

Here `K` and `E` are the complete first- and second-kind elliptic
integrals. The production implementation evaluates them through the
**complementary parameter** `d²/b²` using the bounded standard-library-only
Carlson RF/RD duplication algorithm. This avoids catastrophic cancellation
of `1-m` near the ideal wire. A fourth-order expansion near the symmetry
axis avoids the cancellation in the small radial component. Cartesian
conversion uses the ring's original world axis and signed position, not a
false axial approximation. Coordinates are scaled for numerical range.
The axis limit is the original `kQ/sqrt(a²+z²)` and
`kQz/(a²+z²)^(3/2)`.

**The ideal wire is genuinely singular:** its potential and E diverge.
Points within a world-coordinate representation guard of that ring raise
`SingularField`. `clearance_at` is 3D distance to the ring's ideal wire,
not a physical metal/insulation radius or collision law. Away from this
guard, the field remains finite and differentiable. Nonrepresentable
fields or source geometry fail closed.

## Distinct from the old axial source and from motion

`UniformRingAxisField` remains **unchanged and axis-only**. It continues
to refuse off-axis E/V, retaining historical JEE axial trajectories and
saved records. The new `UniformRingField` is a separate built-in physical
component, accepted by `PrescribedField` superposition and immutable
`NamedSource` identities. The existing `TestChargeMotionSpec` and
`DipoleMotionSpec` explicitly refuse the new source for time evolution:
M27b must separately qualify the invariant motion plane, physical guards
and trajectory before it can be integrated. Static finite-pair dipole
observations may separately use any qualified external E/V; a static
potential does not establish a dynamically admissible path.

There is no forced 1D particle motion, free-3D dynamics, guide force,
field-induced conductor response, current, Maxwell switching
electromagnetics or invented particle mass.

## Reusable 2D static world slice

`sample_ring_field_slice(field, plane, source_annotations=...,
exclusion_width_m=...)` samples the **full 3D** actual E and V of up
to 12 fixed components comprising new rings, point charges and uniform E,
with at least one new full ring. The `SliceSpec` specifies an authored
world-coordinate observation plane. Every actual grid point stores its
world position, electrostatic V, full world E, projected E_u/E_v and
**signed E normal to the plane**. An observation plane is **not** a
particle-motion constraint; nonzero perpendicular E is retained, never
silently suppressed or falsely called a guide reaction.

A grey mask represents teacher-chosen display exclusion **only near real
3D ideal charged wires/point sources**, not an artificial conducting surface,
a zero field or a mask of the entire 2D projection of an off-plane ring.
The source rim is displayed as an explicitly dashed orthographic projection
of the real 3D circle, not a charged rod or material line in the slice.
Saved full E/V numbers and geometry are rechecked by
`validate_ring_field_slice`. The standalone offline SVG contains only
precomputed static values and source IDs. No browser solver, trajectory,
particle animation or actual field-line computation is present.
M21b's old 2D point-charge map contract remains unchanged.

## Public Python authoring example

```python
from conductor_sim import PrescribedField, UniformRingField, UniformElectricField
from conductor_sim.visualization import SliceSpec
from conductor_sim.ring_field_observer import sample_ring_field_slice, write_ring_field_slice

field = PrescribedField((
    UniformRingField(+10e-6, .3, center_m=(0,0,0), axis=(1,0,0)),
    UniformRingField(-20e-6, .3, center_m=(.4,0,0), axis=(1,0,0)),
    UniformElectricField((0,1e5,0)),
))
plane = SliceSpec(origin_m=(.2,0,0), u=(1,0,0), v=(0,0,1),
                  x_range_m=(-.45,.45), y_range_m=(-.45,.45), resolution=37)
data = sample_ring_field_slice(
    field, plane,
    source_annotations=(("ring:A","Ring A"), ("ring:B","Ring B"),
                        ("field:upward","Upward applied field")),
    exclusion_width_m=.012,
)
write_ring_field_slice("output/m27a-two-rings.html", data)
```

This example uses the actual workbook `02_conductors_half_size.pdf`
physical p12 linked Q40–41 values: ring radii 0.30 m, separation 0.40 m,
charges +10 µC and −20 µC, upward 100 kV/m world-y prescribed E.
The *observation plane, grid resolution and exclusion width* are
teacher-authored display choices, not source givens. The physical
transverse field remains visible in the saved normal-component data.
Q40's electrostatic endpoint-work interpretation stays valid; Q41 does
not provide a numerical mass or a hidden axial guide.

```powershell
git pull --ff-only
python -m pip install -e ".[test]"
python -m pytest tests/test_m27a_ring_field.py -q
python examples/m27a_ring_field.py --case workbook-two-rings --output output/m27a-two-rings.html

```

The independent direct Coulomb circular-line midpoint reference (different
from Carlson K/E), finite-difference gradient, charge/medium scaling,
arbitrary rotations/axis reversal, near-axis behaviour, singularity
refusals, source mask and saved-grid tampering are covered by tests.
A reserved numerical card was pinned in `m27a_charter.md` before
production changes and is executed *only after candidate freeze* through
CI, with its first outcome preserved rather than retroactively called
a blind third-party trial.

CI also requires full Python 3.10/3.12, existing 97 real FEMM 5
**conductor nonregressions**, new fixed-source physics and actual Chromium
saved-static-map acceptance, exact final source SHA/tree and an independent
R2 reviewer before separately approved merge. FEMM does not independently
validate the new uniformly charged insulating ring law. A passing static
map or test is not evidence of simulated curved particle motion.

**Known limitations:** ideal infinitely thin line charge, homogeneous
permittivity, nonresponsive fixed sources, finite-resolution 2D observation,
no general off-axis *disc* model, no finite-thickness wire cross-section,
no self-capacitance/induction, no time evolution, no automatic PDF ingestion,
and no claim of representative exam coverage.
