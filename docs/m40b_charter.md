## Purpose and JEE claims

Make the **already-qualified** M40a local inner-wall induced charge density visible for teacher-authored real 3D spherical cavities. A physically neutral *whole cavity face* may have sharply varying positive/negative local sigma; a grounded versus isolated metal affects its outer surface charge but leaves inner-wall densities unchanged for identical fixed sources. All observed states are **static equilibria**. The atlas must demonstrate real named source positions, stable source identities, and actual signed native density samples so teachers can explore parameter/source revisions later without inventing new field laws.

**Original JEE problems newly solved: zero.** No claimed source-faithful irregular-cavity problem solution, general 3D E(x), V(x), force or motion. M39a topology alone never qualifies this physical viewer.

## Admissible source and visual observations

- Accept only genuine `SphericalSigmaModel` and freshly recomputed `solve_spherical_sigma` solution(s). Reuse M39a `GaussCavityAssembly`, original source IDs and charges, actual source coordinates and grounded/fixed-net-charge constraints. Source density must be queried from the existing M40a implementation; **do not change the M40a solver**.
- Author a deterministic, no-network **standalone HTML/SVG** page. Show actual **orthographic XY projection** using one physical metre scale for the outer sphere, all disjoint cavity spheres and each charge's true XY projected position. Show full signed source value, X, Y, **Z** coordinates, cavity center and radius in a separate legible legend. Projection overlap may occur for non-overlapping physical 3D spheres and **is not evidence of intersection**; it is NOT a 2D electrostatic cross-section, 3D field map, field-line rendering or time simulation.
- Render a **discrete spherical-point atlas** for each named cavity: at most 48 genuine admitted unit rays per surface, with the precise θ (colatitude), φ (longitude), world-coordinate ray and signed `C/m^2` on every tile, presented as a readable numeric table or accessible grid. Plot colors may distinguish signs but never replace exact values; no continuous unsolved interpolation/area-averages/integrals are claimed. Include explicit axes and spherical direction convention. A nonempty signed-neutral cavity may have nonzero pointwise samples; an empty cavity has exactly zero at all sampled rays.
- Report **actual M39a whole-face integral Q in C** separately; DO NOT infer it from grid points. Report M40a **uniform outer sigma** from the actual spherical outer face with explicit isolated and grounded values. Never compute local sigma from total-face charge divided by area except qualified outer uniform case.
- Compare **genuinely independent** isolated and grounded static solutions with matching original metal ID, cavity/source order and charges, permittivity, source coordinates, geometry and sampler rays. Requalify both. Equality of inner sigma must be numerically checked at identical original raw rays; outer sigma may change. Preserve original signed zero vs near-cancelled refused values. Do not imply grounding current, chronology, moving source or change in historical teacher input.
- Preserve M40a v2 semantics: a raw near-unit binary64 input direction defines the physical ray; `unit_normal` is rounded for display only. Derive each exported numeric value from a fresh native query of original **raw** direction and preserve unchanged raw data. Do not treat the display normal as a physics input for near-wall queries.

## Evidence, provenance, safety

- Every rendered value and visual geometry comes from a *validated typed physical result*, not from arbitrary JSON or teacher-supplied HTML; names are always escaped in both text/attribute contexts. The standalone viewer-manifest export must be versioned, specify the teacher-hypothetical role, explicitly flag no time/3D field claims, include raw direction and exact signed samples, and retain source identity evidence with a reproducible independent verification path. An externally modified self-consistent JSON is **not** cryptographically linked to past teacher input without a trusted external anchor; say so.
- A source near wall, unqualified scale, mixed constraints, inconsistent geometry or identities, forged material/charge data, Boolean/non-finite/underflowing values, or impossible sigma query must fail closed, not silently draw approximate neutral/zero samples. The separate reviewer must independently calculate some unknown examples with a **real charge + Kelvin image normal electric field**, not copy native Poisson kernel.
- Browser acceptance must use **actual Chromium with JavaScript enabled and disabled**, desktop and narrow mobile viewport, world-scale/geometry/source coordinate and SI text checks, XSS/HTML forgery probes, and absent remote-resource requests. No JS fallback that hides or fabricates physics.
