**Status: draft development, NOT released or independently reviewed.** Frozen [M36e charter](m36e_charter.md), based on M36d owner-authorized merge `8bca8e5d1c157e05b3f04e6185e927bd7ee79941`, native reviewed tree `523d02e95dbb4791acd630f9c535eb552262c606`.

## Why this follow-up

M36d's independent Chat B R2 review verified exact source-authentic **SOLID** conductor geometry and genuine Gauss potential/E/sigma, but identified three small visual shortcomings:

- Students did not see **both originally asked p26 values V(R/2) and V(3R/2) together** in a prominent teaching panel, despite numerical values being authentic in the native manifest.
- The inherited generic heading **“Induced surface-charge profile”** was physically imprecise for an isolated solid sphere carrying a fixed net Q, rather than one with source-induced polarization.
- Sampled potential colours around the circular conductor displayed blocky/white squares at 37×37 preview-grid resolution. Rectangular field sampling near a curved discontinuity is a display limitation, **not a solver error**.

M36e is restricted to a **source-specific viewer refinement** of the already verified one original p26 physical apparatus. It does not add a new original JEE question or change the production solver, physical field laws, M6 historic source, PDF files, FEMM, global M5 viewer, or general physical authorability framework.

## Actual source-backed readouts

`tools/m36d_true_solid_sphere.py` still uses the public `MixedRadialBackend` to compute genuine real `SolidSphere` potential/E/sigma and the existing M5 renderer to draw all physical fields. New source-specific HTML adds a prominently visible panel under the title that, **for the currently selected stored state**, displays actual native:

| Readout | Physical meaning |
| --- | --- |
| `V(R/2)` | Real solver potential halfway inside metal |
| `V(3R/2)` | Real solver potential outside the original solid |
| `|E(R/2)|` | Zero uniform conductor interior field; not a point-source singularity |
| `Outer-face sigma` | True `Q/(4πR²)` signed physical **outer-only** charge density |

The panel also shows source/teacher status, real `R`, signed net `Q`, center position, the `Grounded()` state when relevant, and “only one outer face.” The printed source's R and Q remain **SYMBOLIC**; source state numerical values are explicitly teacher illustrations, while two later frames are expressly teacher hypotheticals. The panel has a readable original-state fallback when JavaScript is disabled and is bound to the pre-existing HTML stored-state slider. It never claims elapsed-time current, heat, discharge, motion or actual physical field re-integration during browser playback.

The source-only density heading becomes **“Surface-charge density (one real outer face)”**; the general M5 viewer still says “Induced surface-charge profile” in real induction scenarios. Other conductor/charged-particle teaching views remain unchanged.

## Authentic field visualization versus interpolation

Original sampled source viewer grid `37×37` is increased to **`65×65` REAL sampled physical field/potential data** in all three states. This is a finer stored grid, not invented continuous physics or FEMM mesh convergence. It can reduce visible sampled-grid artifacts but does NOT mathematically guarantee pixel-perfect/antialiased metal-edge colours. True conductor geometry stays an exact solid disk cross-section with `inner_radius=0`, no false cavity or inner density series, and one actual outer charge profile.
