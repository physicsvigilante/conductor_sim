## Educational goal

A teacher can already add/replace a named fixed source (M22a/M29a), vary a property of that newly introduced source (M30a), and investigate typed detectors or reversals across either source changes (M29b) or a parameter sweep (M28b) separately. Missing is applying **the SAME physical event question across a two-stage model family**: original → separately qualified source arrangement → variations of a property of the introduced source. Events must be actual numerical observations of independently solved trajectories, not presentation markers or interpolated frames.
