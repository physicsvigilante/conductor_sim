# M19a — Prescribed sources and test-charge motion

## Purpose and physical distinction

Refocus on composing fixed-field/energy problems: a particle moves in an
unchanging prescribed electric field. It does **not** change a source charge
distribution, induce conductor charge, or enter the source inventory. Existing
M1–M18 conductor-equilibrium and induced-motion APIs remain available unchanged.

The source observation contract is `potential_at(position_m)` and
`electric_field_at(position_m)`. `PrescribedField` superposes the scalar
potentials and vector fields of up to 64 immutable built-in sources, using one
positive homogeneous permittivity. It does not accept conductor components.

| Source | Implemented observation domain | Motion boundary |
|---|---|---|
| `UniformElectricField` | All space; explicitly prescribed E and reference V | None; no finite electrodes or fringing claimed |
| `FixedPointField` | Away from its fixed point | Positive source-approach guard |
| `UniformRingAxisField` | **Only the symmetry axis** of a thin uniformly charged ring | Axis may cross the ring centre; no axial singularity |
| `UniformDiskAxisField` | **Only the symmetry axis** of a uniformly charged disc | Stop before the ideal surface-field jump |
| `UniformRodField` | Full spatial field of a finite uniformly charged line segment | Stop before the singular segment |
| `UniformSphereField` | Interior/exterior of a fixed uniform volume distribution | Continuous E at radius; crossing is allowed |
| `UniformShellField` | Interior/exterior of a fixed uniform thin surface distribution | Stop before the ideal surface-field jump |

Rings, discs, rods and volume spheres are fixed charge distributions, **not**
new conductor-equilibrium solvers. Volume-source material is mechanically
transparent in this ideal field model; no collision with matter is simulated.
Thin-shell potential remains continuous at its surface but the field there is
ambiguous, so potential sampling is allowed and field sampling is refused.
The same convention applies at the disc centre. Near machine-resolution rod
singularities/shell jumps the observation refuses rather than choosing a side.

## Common authoring API

```python
from conductor_sim import (
    PointCharge, UniformRingAxisField, PrescribedField,
    TestChargeMotionSpec, integrate_test_charge,
)

field = PrescribedField((UniformRingAxisField(1e-9, .1),))
spec = TestChargeMotionSpec(
    field=field,
    particle=PointCharge(1e-9, (0., 0., .2)),
    mass_kg=1e-6,
    initial_velocity_m_s=(0., 0., -.2),
    duration_s=1.4,
    sample_interval_s=.01,
    length_scale_m=.1,
)
result = integrate_test_charge(spec)
```

A second coaxial ring or an axial uniform field can be added to the same tuple.
For full-spatial sources, the launch and each source must preserve an authored
reflection plane (normal defaults to world y). A rod can lie in this plane,
or cross it normally with its midpoint in the plane. For axis-only sources,
the initial point, launch and all other sources must preserve the **same
physical axis**. A perpendicular rod bisected by that axis is also supported.
An automatic plane containing that axis is used unless explicitly supplied.

A transverse applied field added to an axis-only ring is therefore refused,
not projected onto the axis. Unsupported off-axis ring/disc observations
always fail explicitly. Source domains intersect under composition; singular
source cancellations are not simplified into a wider observation domain.
General unrestricted 3D trajectories and arbitrary user callbacks are not
part of this milestone's certified motion domain.

## Force, energy and numerical reuse

The moving particle obeys `m*r'' = q*E(r)`, with `U = q*V(r)` and
`K = m*|v|^2/2`. There is **no induced-energy half factor**. Fixed-source
self/mutual energies are excluded because they are constants for this model.
Finite-source potentials vanish at infinity; a uniform field has an explicit
reference point/value. A constant voltage offset changes U by q times the
offset, not the trajectory or energy drift.

`_integrate_vector_motion` is extracted from the accepted M17/M18 controller
and reused by both conductor motion and test-charge motion. RK4 stepping,
step-doubling error control, output-time scheduling and the original conductor
guards are retained; there is no second production ODE implementation. The
prescribed-source domain supplies clearance and conservative chord checks to
the same controller. The original M16 scalar path still shares the RK4 kernel.

`length_scale_m` is the positive characteristic length used by the existing
error controller, not a source position or collision radius. `source_guard_m`
is a positive approach cutoff, not an impact model. Speeds must stay below
the existing 0.1c classical cutoff; output intervals are bounded by the shared
2,000-interval limit. Smooth volume-sphere boundaries may be crossed; ideal
surface jumps and singular sources stop with a labelled `source-guard` event.
A guard event is not an exact collision time. Tolerances are engineering
controls, not rigorous global error guarantees for every authored value.

## Current output, and what is deliberately next

This physics-first milestone exports genuine elapsed-time **JSON**, schema
`conductor_sim.test_charge_motion.v1`, containing fixed-source provenance,
particle properties, E, V, force, position, velocity, acceleration, K, qV,
K+qV, energy drift and termination events. It is separate from conductor
playback schemas and must not be passed off as a conductor field-map bundle.

The next viewer milestone should reuse the existing time controls and energy
plots with a prescribed-source adapter. In particular, an axis-only ring/disc
must show an axial field/potential profile, not a fabricated 2D field map.
This milestone does not implement that viewer, a new question parser,
time-dependent sources, multiple moving particles, collisions, dielectric
interfaces, or FEMM-derived motion forces.

`rod-deflection`. No new runtime package dependency is introduced.

## Scientific references and verification

Standard formula derivations: OpenStax University Physics Volume 2,
[5.5: fields of charge distributions](https://openstax.org/books/university-physics-volume-2/pages/5-5-calculating-electric-fields-of-charge-distributions),
[7.3: electric potentials](https://openstax.org/books/university-physics-volume-2/pages/7-3-calculations-of-electric-potential),
and [7.4: E from V](https://openstax.org/books/university-physics-volume-2/pages/7-4-determining-field-from-potential).
Ring/disc axial formulas, the finite-rod Coulomb integral, spherical Gauss-law
fields and scalar/vector superposition are implemented without quadrature in
the production source layer. The rod potential uses a rationalized logarithm;
the disc potential uses a rationalized expression to avoid far-field
subtractive cancellation.

Independent tests cover analytical ring turning points from conservation of
energy, exact constant-field parabolas, exact interior-sphere harmonic motion,
volume-boundary transit, numerical Coulomb quadrature of a finite rod,
finite-difference E=-grad(V), both sides of ring/disc fields, sphere/shell
limits, permittivity, source immutability, qV (not qV/2), gauge shifts,
rotations, explicit domain refusals, guards and all eight CLI exports.
Require the retained Python 3.10/3.12, browser/authoring checks and **97 actual
FEMM regressions with zero skips** before merge. FEMM establishes old numerical
non-regression, not prescribed-source force validation. Exact counts and
candidate identity belong in the PR acceptance record rather than being
assumed from this document.
