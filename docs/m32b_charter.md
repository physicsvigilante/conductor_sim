## Goal

A single native physical-world graph must accept this physically meaningful teacher/LLM authoring sequence:

Original fixed-source model → structural source replacement/addition → physical revision of an existing source or true probe initial conditions → another independent structural source add/remove/replace → further independently solved physical hypotheses and native event questions.

M32a intentionally refuses structural-after-physical: the native M22a `ScenarioReassembly` ancestry stops when an M20b `PrescribedScenario` is created. Blindly treating that revised model as a new ancestry root permits a retired named source identity to be recreated, misleading teachers about which source survived and which was retired. **M32b may lift that refusal ONLY by carrying and validating the earlier identities across every graph edge.**

## Acceptance cards

1. **Native mixed-order success:** New field source added under a stable ID, jointly revised with particle mass, then source replaced/removed/added under new IDs, then source/probe physical revision and original typed detector question. Verify each immediate model revision, stable source label/kind, native SI trajectory/event brackets and proper unique duration-complete same-direction pairing only where applicable. Verify M22a assembly after physical truly has the immediate physical model as parent.
2. **Retired-ID attack:** Add `field:temporary`, replace it with `field:replacement`, physically revise a real independent probe mass, then try to add or replace a new source using old `field:temporary`. Old M22a would lose this history at the physical node; **M32b MUST refuse** it, with no generated child model/trajectory and unchanged successful sibling. Check both add and replacement, and rejection of any incoming ID equal to currently active source ID.
3. **Branch independence:** The same new ID can be used on two independent alternate source-world branches from one original provided their branch-local ancestry never used it before. Do not invent a global registry or confuse separate hypothetical worlds.
4. **Accepted-but-observation-refused parent:** A fully admitted physical parent whose M24a event-study refuses may still have a native valid structural child that is independently observed, while the parent event numerical comparison is explicitly unpaired. A physically invalid world has no source certificate, and descendants must be skipped.
5. **True 3D physically qualified transfer:** An unfamiliar supported fixed point/tilted rod/gravity/world source arrangement with actual physical source/initial-condition revision, followed by structural operation, should match independent direct SI Coulomb/analytic force or high-accuracy ODE reference. No silent projecting off-plane forces onto a fake 2D path. Preserve all actual source IDs.
6. **Guards/multiple roots:** Real source guard can preserve an earlier root and censor later detectors; bidirectional two-root history cannot be converted to unique event pairing, even after mixed-order revisions. Actual saved event/native SI clocks only.
7. **Full ancestry and evidence adversarial checks:** Direct public dataclass replacements to plan flag, source label, source active/seen/retired IDs, parent/revision chain, physical edit values, structural ledger, event time (+0.03s), Boolean zero timestamp, fake `rejected-event-study` status, or replacement of native result object must fail constructor and pre-export validation. Wrong source ancestry type and historical unknown source ID must never become a successful admitted world.
8. **Backward compatibility:** All M32a native tests pass unchanged when policy omitted; default still refuses structural-after-physical, keeps identical legacy v1 JSON output and no extra v2 fields. When enabled, new v2 evidence must be detached, finite and explicitly explain ancestry root limitation.
9. **Numerical and release gates:** Source-HEAD Python 3.10 and 3.12, historic dedicated 97 real FEMM checks, real Chromium and independently expressed unknown physics transfer, graph-source identity and adversarial regressions, all exact SHA/tree verified. Preserve failed runs as failures.
