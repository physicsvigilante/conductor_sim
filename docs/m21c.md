# M21c — Composite reflection symmetry and JEE charge motion

## Source and correction to the earlier audit

`POTENTIAL_CONDUCTORS1.pdf`, physical page 13, Illustration 7, fixes two
charges +Q at (0,+a) and (0,-a) and launches a particle -q of mass m from
the origin along +x. It asks for the launch speed that produces a turning
point at x=sqrt(3)a, and for the threshold escape speed. The original page
was inspected visually and the file SHA-256 is checked by the example:
`8d0d9b5cf821219058cfc4b7685a39b777e460944df44c3f9cffcb68157a60e5`.
This is a teaching illustration, not a verified official JEE past-paper item.

**Correction:** M21a overstated the limitation for this specific example.
The existing solver already accepts it in the xy plane containing both fixed
sources (`plane_normal=(0,0,1)`). The default xz plane was refused because
neither source individually belongs to it. M21c's actual extension is
qualification of a source inventory that preserves a plane *jointly* through
reflection, plus explicit JEE motion examples and analytical checks. It is
not a newly implemented Coulomb law or the first possible solution of p13.

## Small reusable engine change

`source_symmetry.certify_point_reflection` checks an ordered inventory of
1–64 built-in fixed point sources. Each on-plane source is unchanged by
reflection. Off-plane sources must pair one-to-one at reflected positions,
with **exactly equal signed charge** and preserved multiplicity. A source
cannot be reused to qualify several different partners; source order does
not decide success. The record reports original indices and residuals.

For a plane through o with unit normal n, reflection maps a displacement d to
`d - 2(d dot n)n`. A reflection-invariant signed source distribution has an
even potential normal to the plane, and hence zero normal electric field
on the plane, away from source singularities. Initial position and velocity
in that plane therefore generate planar motion under the ordinary full
force law. The two-charge perpendicular-bisector line is the intersection
of two such invariant planes, not a mechanical guide.

Geometric matching allows 64 ulps of floating-point representation. If that
allowance exceeds 1e-11 of the local source span, the proof is refused as
poorly resolved. This is roundoff accounting, not approximate charge equality,
a tunable physical symmetry, or snapping source positions. Numerical step
size and tolerances cannot relax the charge/geometry match.

`prescribed_motion._certify` retains the old individual-source checks where
they already suffice. For a previously refused nonaxial point inventory it
uses the new joint certificate. All other source families still need their
original qualifications. Axis-only rings/discs remain axis-only. No source
is moved, merged, discarded, or converted to a ring; no transverse force is
projected out. The unchanged adaptive vector integrator and its runtime
normal-force checks, source guards and speed limit still apply.

A valid model remains distinct from successful integration, and symmetry in
an exactly authored setup does not establish stability to physical perturbations.
Broken symmetry can still be studied in another qualified plane, but is never
silently forced into the previously symmetric plane.

## Independent JEE references

Let q denote the positive magnitude of the moving negative charge. On x,
`V(x)=2kQ/sqrt(a²+x²)` and `U(x)=-2kQq/sqrt(a²+x²)`.
Conservation of `m v²/2 + U` gives

- Turning at x=sqrt(3)a: `v0=sqrt(2kQq/(ma))`.
- Threshold escape: `v_escape=sqrt(4kQq/(ma))`.

The example uses **illustrative** Q=q=1 nC, m=1e-6 kg (one milligram),
a=0.10 m. A separate energy-time quadrature checks the turning-time bracket;
it does not read expected timing from the production RK trajectory.
Fixed-source mutual energy is a constant and omitted from the moving probe's
K+qV, not confused with the factor-one-half induced-charge energy convention.

Four reproducible cases:

| Case | Teaching purpose | Provenance |
|---|---|---|
| `turning` | Launch, turning near sqrt(3)a, return through origin | Source symbolic relation, illustrative SI quantities |
| `escape-threshold` | Zero total probe energy at threshold speed | Source part (ii); only finite physical time displayed |
| `above-escape` | Positive energy at 1.1 times threshold | Explicit teacher hypothetical, immutable M20b revision |
| `mirror-plane` | Genuine oblique 2D motion in xz with both fixed sources outside that slice | Explicit teacher hypothetical exercising the new qualification |

No finite animation claims that the particle reaches infinity. The turning
position and reversal are checked from saved physical samples; the displayed
time interval is a bracket, not an exact event-time solver.

## Viewer fidelity and validation

The existing shared viewer and procedural drawing routines are reused.
Source-visible examples use the xy plane. Its screen orientation is stated
in world coordinates; it is rotated relative to the printed diagram.
For composite symmetry the existing point renderer correctly omits off-slice
sources; M21c adds explicit notes naming each omitted ID, world position and
signed normal offset. Their full field remains included. They are not drawn
as invented in-plane charges. Default in-plane export data remains unchanged.

Tests include multiple pairs, signed charges, source order and multiplicity,
rotation/translation covariance, instantaneous-but-not-global cancellation,
source-law and energy references, real returning/escaping behavior, runtime
force refusals, immutable revisions and recertification when only one source
is changed. Chromium checks actual painted source markers, omission notes,
saved-time controls, trajectory/force/velocity drawing, mobile width and
absence of JavaScript errors or external network requests. FEMM checks are
nonregressions of existing conductor physics, not the solver for these sources.

## Reproduce

```powershell
python -m pip install -e ".[test]"
python examples/symmetric_charge_motion.py --case turning --output output/m21c-turning.html
Start-Process .\output\m21c-turning.html
python examples/symmetric_charge_motion.py --case escape-threshold --output output/m21c-escape.html
python examples/symmetric_charge_motion.py --case mirror-plane --output output/m21c-mirror-plane.html
python -m pytest tests/test_m21c_source_symmetry.py -q
```

Each HTML has a detached JSON audit containing the authored immutable
scenario, provenance, certificate, real samples and independent references.
The capability remains prescribed-source classical motion in qualified
planes, not responding/moving source charges, arbitrary 3D motion, new
conductor topology, or automatic interpretation of any JEE problem.
