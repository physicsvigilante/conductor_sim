## Gap and educational purpose

A teacher can already make a *jointly admissible* revision of 2–4 physical properties on one named original or separately reassembled source world (M31a). M24a can ask physical detector-plane crossing or velocity-reversal questions, but existing M28b/M29b/M30b adapters do not directly observe an **M31a atomic coupled hypothesis**. The missing composition is: *change two physical properties together in a valid full model, then ask the same genuine event question of that specific world and compare the result against its actual immediate parent.* No event can be inferred from interpolating the ordinary M31a trajectory or from an independently invalid intermediate single-property model.

## Frozen acceptance cards

**P1 — Analytical detector, true two-property edit.** Use M29a `uniform-edits` structural `add-E`: original uniform E_x=100 V/m, structural parent adds named `field:Enew`, and coupled child revises `field:Enew.field_v_m` together with `test-particle.mass_kg` (M31a example: 150 V/m and 2e-5 kg). With genuine q, initial x and vx, same signed x detector in duration, independently solve the quadratic `x(t) = x0 + vx0*t + q*(Ex_total)*t*t/(2*m)` for each actual world. Check source IDs, exact parent SHA, three fresh M24a event trajectories, root signs/brackets and parent→child numerical shift.

**P2 — Jointly valid shifted point and probe.** On `point-replace`, translate held point and probe initial *physical* positions together in world z by +0.05 m. Each unilateral revision must still refuse, the M31a coupled model must be admitted. A real x-plane detector sees the same unique physical event time before/after this rigid translation (within numerical tolerance); event integration must use true 3D positions, not silent projection or a fictitious source trajectory.

**P3 — Gravity plus electric field.** Independently check a unique signed y crossing with exact constant-acceleration equations when a newly admitted `gravity` component and an existing electric component are jointly modified. Ensure separate qE and mg, signed event direction and complete native observation.

**P4 — Genuine guard-censored observation.** Use an attractive held point source case with a real source guard. Retain any genuine earlier detector root while refusing whole-duration unique-event pairing; a far detector beyond the guard is unresolved/truncated rather than proved absent. Preserve last actual saved SI sample.

**P5 — Multiple roots/directional mismatch.** A real retarding uniform field admits two bidirectional detector crossings in one complete trajectory. Preserve both native roots and signed directions; never silently pair first roots or opposite-direction events.

**P6 — Event-study refusal without physical refusal.** Construct a physically admitted parent that fails M24a event-study qualification, while an independently admissible two-property child admits the same observation. Parent has no event run, the child does; their numerical event shift remains unpaired. Keep sibling cases running.

**P7 — Independent stage/identity/adversarial coverage.** Structural refusal, unavailable accepted structural parent trajectory, absent retired source target, gauge-only or no-op edit, full-world physical qualification refusal, and one successful independent sibling. Negative cases include invalid question inventory, forged nonnative `EventRun`, mismatched scenario and policy, unknown termination, invented timestamp/root, mutated evidence before JSON export, Boolean SI time and custom equality. No fabricated trajectory, source inventory, parent or successful status may pass.

**P8 — Unfamiliar numerical transfer.** Independently author a tilted finite charged rod, signed fixed point charges, gravity and a newly introduced adjustable named point source with a **coupled** source-charge + probe-mass revision. Choose a bounded genuine detector plane crossed in admitted scenarios, then check native event signs and bracketed crossing times against a separate Coulomb quadrature + high-accuracy SciPy DOP853 calculation. Report independent reference accuracy and source assumptions; do not import production solver callbacks into the independent reference.
