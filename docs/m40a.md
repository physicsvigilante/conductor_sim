## Real new physics, strictly qualified

M39a/b compute reliable complete-face Gauss totals for a conductor with abstract sealed voids, but have **no physical source positions or cavity geometry**. M40a attaches real three-dimensional source positions and actual **nonoverlapping spherical cavity/outer-metal radii and centers** to the same immutable \`GaussCavityAssembly\`. Strict geometry checks prove actual source containment, disjointness, finite wall gaps and global M39a physical IDs. This enables the exact local metal-side **inner spherical induced charge density** in C/m² at an explicitly requested outward-from-center unit normal. It is mathematically equivalent to the Kelvin image Dirichlet solution at each cavity boundary; Gauss law still guarantees the integral over each entire spherical face is -sum(enclosed source charges).

Because every void lies within **the same connected ideal metal**, each inner spherical face's local induced sigma is independent of every other cavity's charges and of the isolated-vs-grounded potential offset. The outer surface is genuinely spherical too: with no exterior charges/fields, its charge density is uniform Q_outer/(4πR_outer²), zero when grounded. This is **not** a separate conductor or fictitious concentric-shell replacement for each cavity.

With a pair of opposite charges at distinct positions, the total induced face charge may be exactly zero yet **local sigma remains nonuniform**. Moving one source within its cavity changes its local sigma, not the whole-face integrated charge. The engine only samples **surface density**; no local E/V maps, source forces, time-dependent wire current, external sources, dielectric interfaces, arbitrary irregular conductor boundaries or FEMM 3D results are implied.

All examples are teacher-authored and **zero new original-source JEE answers** are claimed. The original p11 linked two-cavity and p70 irregular 3D problems remain unsupported for local fields/densities; this new spherical model is a new separately qualified pedagogical class.

## Independent review #01 correction — surface normals

The first independent [scientific review](https://github.com/physicsvigilante/review_sandbox/pull/23) correctly identified an admitted near-unit radial input that was used as an off-sphere evaluation point at an almost-touching source. A raw direction length of `1+9e-13`, allowed by the `1e-12` norm tolerance, changed the local density by about 0.0225% within the supported 1.2e-8 relative gap. This is a genuine numerical surface-location error, not a problem with the Kelvin theorem. The initial B1 correction normalized accepted near-unit directions in binary64 before calculating and saving them; the later independent review #02 found that this still loses oblique-angle precision near an admitted source-wall gap. The corrected source instead validates the raw direction without replacing it, then uses high-precision normalization on the actual spherical wall before local-density evaluation. The independent reference derives real+image fields directly from the recorded raw direction. Regression tests retain the reviewer's near-wall exact pole, forged old off-surface JSON, negative charge/isolated case and an oblique physically aligned source. The original CHANGES REQUESTED report and first attempt remain preserved. A focused independent corrective review is still required; no merge is authorized.

The original B1 corrective test additionally revealed a source-wall near-contact arithmetic-conditioning issue for oblique normals: ordinary binary64 vector subtraction can misplace the nearly coincident wall/source separation by several ulps, magnified by the inverse-cube Kelvin density. M40a now evaluates only the **small near-wall clearance branch** of the exact closed-form spherical Poisson kernel with 90-digit Decimal arithmetic and re-normalizes the admitted direction on the physical sphere at that precision. The independent reference independently evaluates the separate real-plus-image normal electric field with a high-precision unit vector. A numeric oblique near-wall fixture enforces the independent expected value without relaxing the original `2e-10` relative reference tolerance. This narrower numerical qualification does not extend the set of admitted physical shapes, forces or source claims.

## Independent review #02 — physical raw-direction fidelity (record v2)

The original #02 CHANGES REQUESTED report, failed reviewer CI and scientific reproducer remain preserved.
