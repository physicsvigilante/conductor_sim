# M39b — JEE-first sealed-cavity topology-only comparison viewer

**Scope:** An accessible, completely offline **static schematic**, never a physical geometry, visualization of irregular 3D fields or a new source-PDF answer. The independently frozen charter is [m39b_charter.md](m39b_charter.md); tracker is [issue #97](https://github.com/physicsvigilante/conductor_sim/issues/97).

## What students learn

The abstract dashed outer frame represents **one connected metal identity** and contains cards for sealed teacher-assigned cavities; the row/card positions, sizes, shapes and grouping are **not spatial coordinates or actual cavity geometry**. Each card shows stable source IDs, exact signed admitted SI Coulombs, enclosed signed sum and the **total induced charge integrated over the complete inner metal face**. An empty void is distinguished from a cavity containing nonzero +/− sources with net zero; neither zero total implies that the local surface density is zero.

A separate table compares two genuinely distinct *static teacher hypothetical* scenarios for the **same immutable source inventory and permittivity**. Isolated metal has authored Q_metal, its outer-face charge and exterior Gauss flux; grounded metal has zero potential, the equilibrium Q_metal=-Σq, zero outer-face charge and zero exterior E by uniqueness in the no-exterior-source domain. None of this is a time animation, physical ground-current history, local field-map, source force or verified geometric containment.

## Example / reproducibility

From the repository checkout:

~~~sh
python -m pip install -e ".[test]"
python -m tools.m39b_topology_example --output-dir output/m39b
python -m tools.m39b_topology_reference --input output/m39b/m39b-topology-view.json --output output/m39b/independent-manifest-witness.json
python -m pytest tests/test_m39b_topology.py -q
~~~

Open \`output/m39b/m39b-topology-view.html\` locally. It has **no JavaScript**, remote fonts, network requests or remote assets. A teacher's source identities are escaped, and every visible numeric value is generated from an authentic validated M39a Gauss ledger with a round-trip-safe SI display.

Raw native records live in \`m39b-isolated-native-gauss.json\` and \`m39b-grounded-native-gauss.json\`. The versioned \`m39b-topology-view.json\` contains both independent states, frozen source topology and source/teacher claims. The separate stdlib-only \`tools.m39b_topology_reference\` verifies M39a SI mathematics without importing the production solver, then checks pair identity, displayed rows and no-geometry/no-time provenance. No unanchored self-consistent JSON can attest its historical origin.
