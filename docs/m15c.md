# Post-M15 correctness review and M15c open authoring trial

## Reproduced and corrected defects

The review started from main `bceae85c8285e81b3dec8302ce09fcdc786b97fd`
(tree `47ed4b42ed095d9c491f16bc1b95e0b29f701075`). All **530** original
non-FEMM tests passed locally. Of 16 new focused regression cases, **9 failed
before corrections and 7 passed**. These are test counts, not distinct bug counts.

1. `NestedShellBackend.supports()` sorted spherical radii before validating
   conductor types. A `ConductingPlane` caused `AttributeError` instead of a
   safe capability refusal. Validate all shapes before sorting; `solve()`
   continues to raise the intentional `UnsupportedProblem`.
2. Default position-sweep framing considered only the first spherical
   conductor, clipping sufficiently large outer shells and depending on
   authored conductor order. It also used arbitrary tangential plane anchors
   for bounds, potentially zooming an unchanged model out enormously. Use
   all spherical extents and physical perpendicular plane distances.
3. Cavity energy split used `V_total - V_background` to recover source
   induction. With a large prescribed shell charge, rounding erased the
   smaller source response. Compute the two radial voltage responses
   separately, before adding their contributions.
4. Work used subtraction of already-rounded total energies. A large constant
   background could make a genuine nonzero displacement work appear zero.
   Subtract direct, induced and background energies componentwise, then
   combine with `math.fsum`. This does not promise arbitrary precision when
   an individual component itself has unresolved differences.

The dynamic-range stress deliberately uses an extreme shell charge to expose
floating-point cancellation; it is not a physical high-field material model.
For the regression q=1 nC, cavity a=.10 m, movement r=.02→.06 m, the previous
work became zero under a huge fixed background. The correct work is about
**−2.340508279e−8 J**. Individual absolute totals may still round to the same
float, while the component-preserving work remains resolvable.

### Uniform cavity-voltage calculation

For independent concentric shells, stop the radial potential sum at the
nearest grounded shell; if none is grounded, extend it to infinity.
Each interior radial gap contributes `(1/b_i - 1/a_(i+1))`; the final exterior
term is `1/b_last` only when no shell is grounded. The source-dependent uniform
voltage is `k * Q_sources * sum(weights)`. The source-free background is
`k * sum(enclosed prescribed shell charge * weight)`.
These are exact linear Gauss-law responses, not a new electrostatic model.
In particular, a grounded innermost shell makes both terms zero regardless
of outer charge. The image-induced force and the half-weighted image-energy
kernel are unchanged.

## M15c: fresh models using the accepted engine

Twelve original prompts are separated from the assistant-authored models
and independent grading references:

- `m15c/questions.py`: natural-language prompts, not PDF transcriptions.
- `m15c/attempts.py`: model components and `PositionSweepSpec` only, no
  import from the reference or expected numerical outputs.
- `m15c/reference.py`: independently constructed Kelvin image positions and
  strengths, Coulomb pair interactions, and radial voltages calculated from
  physical spherical surface potentials. It imports **no conductor_sim code**.
- `m15c/evaluate.py`: validates units, source identity, radii, net-charge/
  ground constraints, initial position and endpoint before observing any
  solver results. Every stored state is checked against the independent
  reference. Simpson integration of force provides a separate work check.

The eight analytical cases include a centered positive charge, negative
charge displaced inward, translated isolated cavity and oblique path, signed
sources whose solver sort order changes, nested shells with a distant grounded
outer boundary, shielding by an inner grounded shell, a connect–disconnect
sequence, and a zero-net pair that still has nonzero individual forces.
Each has five stored equilibria: **40 states checked**.

The connect–disconnect case is intentionally precise: M14's connection
compiler resolves the initially wired conductors, then the wire is **removed**
and the resulting individual net charges remain fixed during the M15 sweep.
This exercises composition of existing capabilities, not a new time-dependent
wire or continuously connected-source energy model.

Four requests are explicitly refused: crossing metal, colliding ideal point
sources, elapsed-time particle dynamics, and FEMM-derived force/energy.
Two invalid geometry refusals are also tested directly against the engine.

**This is one open assistant-authored engineering trial, not a blind LLM
accuracy or generalization score.** Eight executable cases and four justified
refusals must not be described as twelve solved physics simulations.
No new PDF coverage is claimed; prior frozen PDF evaluations remain historical.

## Run and preview

```bash
python -m m15c.evaluate list
python -m m15c.evaluate grade --output output/m15c-report.json
python -m m15c.evaluate render negative-inward --output output/m15c-inward.html
python -m m15c.evaluate render nested-ground --output output/m15c-nested.html
python -m m15c.evaluate render connect-disconnect --output output/m15c-connected.html
```

Exports reuse the existing HTML viewer, force arrow, synchronized force/energy
plots, work display and line-density control. Playback selects **positions**,
not time. Off-plane three-dimensional fields are not falsely traced as 2D
field lines. A custom explicit slice may still intentionally crop the view;
the framing correction concerns the default helper.

Acceptance requires the full Python 3.10/3.12 suites, retained source/Chromium
checks, the focused M15c browser workflow, and all retained actual FEMM
regressions without skips. Numerical FEMM force support remains unavailable;
those regressions are non-regression evidence, not FEMM validation of M15
forces. No older numerical tolerance was relaxed, and the deferred small
white sphere-boundary patches are untouched.

Physics foundations: Kelvin images and reciprocal electrostatic Green
functions (M. Fowler, University of Virginia), and energy accounting for
induced charges (R. Fitzpatrick, University of Texas at Austin):
- https://galileoandeinstein.phys.virginia.edu/Elec_Mag/2022_Lectures/EM_08_Images.html
- https://farside.ph.utexas.edu/teaching/355/Surveyhtml/node85.html

These references support the underlying electrostatics, not certify this
implementation. Exact test counts and workflow IDs belong in the PR's
acceptance record.
