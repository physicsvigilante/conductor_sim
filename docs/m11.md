# M11 — Compose multiple independent source charges above a grounded plane

M11 extends the **M10 FEMM 5 numerical compiler**, not the physical model, exact
image-charge backend, or renderer. `ElectrostaticProblem` still contains typed
`PointCharge` components and a single `ConductingPlane(Grounded())`. The
analytic `GroundedPlaneBackend` is unchanged and solves arbitrary 3D charges
in the positive-normal half-space.

## Numerical capability (strict)

`Femm5PlaneBackend` now accepts up to **16 distinct active charge sites** on
one normal line through the infinite plane: every source must have the same
orthogonal projection onto the plane. The normal and footpoint are inferred
from the authored world-space 3D geometry, including rotated/translated planes.
This is the actual axisymmetric domain of a conducting plane with point
charges; mere collinearity along an arbitrary tilted axis is insufficient.
Non-collinear FEMM requests raise `UnsupportedProblem` **before starting FEMM**,
not a silent dimensional approximation. A charge on or below metal is rejected
whether or not it would be cancelled by a coincident opposite charge.

Charges at exactly coincident positions combine with compensated summation;
fully cancelling positions are omitted. Independent active sources remain
independent FEMM source cores even if their **total charge is zero**. Each
regularized source is a finite spherical conductor with separately assigned
fixed net charge and separately postprocessed numerical charge, distinct from
the real grounded plane. Core radii are bounded by height, neighboring core
separations and outer-boundary clearance. All source cores are masked in
numerical visualization. The old one-source
`source_position_m`, `source_radius_m`, and `numerical_source_charge_c`
properties retain their M10 meaning; for multi-source solutions these ambiguous
single-source properties are `None`, with every distinct core stored in
`numerical_sources`. The finite numerical hemisphere and its exported source
masks are centered at the **common source footpoint** on the plane, not at the
author's arbitrary plane anchor. This is exercised by a translated-plane
visual-domain regression.

## Measured finite-plane charge versus exact infinite-plane charge

For charges q_i at heights h_i > 0 on one normal, the ideal infinite-plane
induced charge is -sum(q_i). FEMM cannot mesh an infinite plane: its
single grounded conductor boundary is a disk of finite radius R. The
**independent exact image-charge integral over that same disk** is

    Q_disk(R) = -sum_i q_i * (1 - h_i / sqrt(h_i**2 + R**2)).

Use this disk quantity, **not** the infinite-plane total, when benchmarking
FEMM's measured conductor charge. The outside-domain charge tail
can be nonzero even when the authored charges sum to zero. FEMM applies M10's
approximate dipole Robin outer condition, with mesh/core-radius and outer-domain
sensitivities checked separately. As in M10, `surface_charge_density_at`
estimates epsilon*E_normal just above the plane, not an independently
measured surface-charge integral or an error bound.

## Authoring and previews

```bash
python -m pytest -m 'not femm5' -q
python examples/femm5_multi_plane.py --output output/multi_plane.html
# Real FEMM 5 binding and headless solver required for numerical output:
python examples/femm5_multi_plane.py --backend femm --resolution 25 --output output/multi_plane_femm.html
```

The offline self-contained viewer shows three stored states: two positive
charges, opposite charges of nonzero net charge, and a **zero-net real-charge
dipole** with charges at different heights. It does not perform browser-time
physics solves, animate motion or introduce a scene graph. Non-axisymmetric
multi-charge problems are **analytical only**.

## Acceptance

The ordinary Python suite exercises exact source preservation, all separate
FEMM conductor commands, grouped site cancellation, capability guards,
translation/rotation, no phantom core in the viewer and M10 compatibility.
The pinned *real* FEMM 5 numerical workflow separately checks independent
source charges, plane Q and V, sampled potential/field, near-plane density,
zero-net dipole, mesh/domain/core settings, world transformation and explicit
non-axisymmetric rejection. See [M11 numerical acceptance](m11-acceptance.md)
for verified results after the live gate.

Limitations: one grounded infinite plane only; 1–16 active sites for FEMM, all
normal-axis aligned; analytic non-collinear multiple sources are supported but
not by axisymmetric FEMM. Numerical near-contact accuracy is unproven;
production hard process timeouts and isolated or multiple planes remain future
work. Analytical force and energy are **not** FEMM force/energy measurements.
