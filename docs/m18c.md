# M18c — Independent held-source motion authoring trial

## Scope and baseline

Baseline: accepted M18b commit `77a8605585a0869c402097d7460acd672826dff0`,
source tree `4a4c3cd38051387ef5737b80118eb8d6d74cb1a0` (PR #34).
The retained GitHub source archive was reconstructed and its whole Git tree
matched this baseline. This milestone adds original problems, separate
reference physics, grading, mutation tests and a repeatable review workflow.
It changes **no production force law, integrator, renderer or numerical
acceptance tolerance**. Stale M18a viewer-refusal wording in the
roadmap is clarified to reflect the already accepted M18b implementation.

There are **12 original prompts: 8 supported trajectories and 4 explicit
refusals**, not 12 solved trajectories. Each supported case has 21 checked
states including the initial state: **168 states total**. This is one open
assistant-authored engineering trial. The same assistant authored prompts,
models and reference code; there was no independent human reviewer or blind
LLM test. No additional textbook-PDF coverage or natural-language parser is
claimed.

## Compositional cases

| Case | Composition | Moving index / held count |
|---|---|---|
| `plane-three` | Three signed charges above a grounded plane | 1 / 2 |
| `tilted-plane` | Translated and tilted grounded plane | 1 / 1 |
| `grounded-sphere` | Exterior moving charge plus a held charge | 0 / 1 |
| `isolated-sphere` | Fixed-net-charge sphere and three real charges | 1 / 2 |
| `cavity-three` | Three charges inside a grounded spherical cavity | 2 / 2 |
| `nested-cavity` | Fixed-charge inner shell, grounded outer shell | 1 / 1 |
| `biased-plates` | Nonzero plate potentials, induction and a held charge | 1 / 1 |
| `centre-release` | Initially stationary central charge and two held sites | 2 / 2 |

Refusals: two simultaneously moving charges, a source arrangement that
breaks the required invariant plane, numerical-FEMM-only dynamics forces,
and time-dependent plate voltage. Substituting a convenient supported model
for these requests is not counted as a solution.

The supported submissions use only existing public `PointCharge`, conductor
components, `ElectrostaticProblem` and `Motion2DSpec`. There are no case-specific
production force laws or integrators. All remaining charges are externally
held at zero velocity. Their supports may exert forces but do no mechanical
work at zero displacement. The moving particle's angular momentum or
in-plane tangential velocity need not be conserved in these multi-source
arrangements; the grader does not impose the single-source invariants.

## Separate prompt, model, reference and execution paths

- `m18c/questions.py`: original textual prompts with units and source order.
- `m18c/attempts.py`: assistant-authored public-API compositions and refusals.
- `m18c/reference.py`: standard-library-only keys, boundary Green functions,
  an independent shell-constraint solve and test-only velocity-Verlet paths.
- `m18c/evaluate.py`: pre-solve prompt checks, independent full-series grading,
  and a separate production-only export path.

The reference module imports neither `conductor_sim`, the authored submissions,
nor previous benchmark reference code. Import-structure tests enforce that
separation. Rendering calls existing `sample_motion_2d` and `write_visualization`;
tests make reference-force and reference-trajectory calls fail during export.
Thus test-only calculations cannot silently become the displayed physics.

## Reference derivation and numerical limits

With `k = 1/(4*pi*epsilon_0)`, the reference mechanical potential is the
pairwise direct Coulomb energy (each real pair once), plus the half-weighted
source-induced boundary potential, plus the full source-free applied potential.
Divergent point self energies and conductor-only constants are omitted, as
in the documented production energy convention. Constant held-source terms
are retained. Grounded-plane mirror charges and grounded-sphere Kelvin
images are standard results; see Richard Fitzpatrick's [method of images
lecture](https://farside.ph.utexas.edu/teaching/em/lectures/node64.html) and
Michael Fowler's [image-method lecture](https://galileoandeinstein.phys.virginia.edu/Elec_Mag/2022_Lectures/EM_08_Images.html).

For spheres the test reference does not construct image positions. It uses
the reciprocal induced kernel, with vectors relative to the sphere centre:

```
H(r,s) = -a / sqrt((r.r)*(s.s) - 2*a*a*(r.s) + a**4)
```

For both the exterior grounded sphere and interior grounded cavity this is
the Kelvin induced potential per `k*q`. The minus-gradient with respect to
the first point supplies its field. Reciprocity supplies the second equal
contribution when differentiating the half-weighted induced energy. The
formula is finite at the cavity centre, including a centred source. Tests
check grounded-boundary values, reciprocity, known single-source limits and
finite-difference energy gradients in all supported cases.

For an isolated exterior sphere with fixed charge `Q`, define
`S = sum(q_j / |r_j|)`. Add `k*a*S*S/2` to the induced energy and `k*Q*S`
to the background energy. Their gradients give the central compensator and
fixed-Q forces. For nested cavities an independent small linear system
solves outer-face charges using Gauss's law, fixed shell charge and grounded
surface-potential equations. The resulting uniform cavity voltage is split
into its source-induced and source-free components, with half and full
weights respectively.

The plate reference sums the ordinary lower-plane-oriented infinite image
construction at orders 256 and 512. It does **not** import the production
reciprocal two-orientation truncation. The production benchmark backend
explicitly uses image order 256 rather than its default 48; induction is
retained in both calculations, not approximated away as a uniform field.
Their different finite truncations are compared with stated tolerances.
The saved grading report records the reference order-doubling differences.

All eight trajectories are independently integrated with velocity-Verlet at
64 and 128 substeps per output interval. Reference convergence must be below
`1e-9 m` in position and `1e-8 m/s` in velocity. Production trajectories are
compared at every output state, with a `2e-9 m` position gate and a
`1e-9 + 3e-7 * reference_speed_scale` velocity gate. Force, acceleration and
energy comparisons use explicit scale-based tolerances. Plate-image order
convergence is separately checked. These are engineering convergence checks,
not a rigorous global error bound or validation of near-contact singularities.

## Negative controls and invariance

The new tests reject wrong mass conversions (1 mg is `1e-6 kg`), charge signs,
held positions, moving indices, missing sources, constraints, geometry,
permittivity, launch velocity and output times before integration. They also
reject corrupted graph-only rows and nonfinite data. Extra or missing prompt
identifiers make the overall trial unaccepted even when remaining entries pass.

Two especially important negative controls deliberately keep plausible data:
a single-charge trajectory relabelled as a held-source trajectory, and a
constant energy offset that preserves motion and apparent conservation but
contradicts the declared full-configuration energy convention. Both must fail.
Reordering sources with the moving index updated, rigid rotation/translation,
and shifting both plate potentials together are checked separately. The last
changes energy by `sum(q) * voltage_shift`, not the trajectory.

## Reproduce

From the repository root after `python -m pip install -e ".[test]"`:

```powershell
python -m m18c.evaluate list
python -m m18c.evaluate grade --output output/m18c-grade.json
python -m m18c.evaluate render plane-three --resolution 19 --visual-frames 12 --output output/m18c-plane.html
Start-Process .\output\m18c-plane.html
```

Use any of the eight supported case identifiers in the table. Each render
produces standalone offline HTML plus matching JSON, keeping all 21 time
samples and solving only selected genuine field frames (at most 24).
Low-resolution review grids deliberately retain unresolved or excluded cells;
they are not filled with invented values.

## Acceptance contract

Require Python 3.10 and 3.12, all retained visualization/Chromium and M15c,
M17c and M18b checks, the new M18c review workflow, and **all 97 actual pinned
FEMM tests with zero skips** before merge. Local deselection of FEMM tests
is not numerical acceptance. The new review workflow retains grade JSON,
JUnit output, commit/tree identity, three offline browser exports and
screenshots, using the existing M18b browser checker unchanged.

FEMM establishes earlier numerical-domain non-regression, not FEMM moving-
charge force accuracy. This milestone does not implement coupled moving
particles, arbitrary 3D motion, collisions, finite-plate fringing, changing
voltage, or a new solver. Saved-data consistency is not authentication of
arbitrarily edited histories. Exact validation results are recorded in the
associated pull request and retained artifacts, not assumed from this document.
