# M8 — External point charge near an isolated solid conducting sphere

**Status: candidate under live FEMM 5 review.** M7 remains an independently
accepted grounded-only baseline. M8 extends the **same physical `SolidSphere`**
component and the same exterior FEMM geometry to `FixedNetCharge(Q)`.

## Geometry and authoring

One real `SolidSphere(a, FixedNetCharge(Q), center_m=...)` and one nonzero
`PointCharge(q, position_m=...)` located at distance `d>a` from the centre.
The sphere remains isolated: **its net charge is prescribed and its potential
is calculated**, never set to zero. Grounding is the different boundary
condition `Grounded()`; it allows its net charge to change.

`ExternalGroundedSphereBackend` stays strictly grounded-only and unchanged.
`ExternalIsolatedSphereBackend` solves the new exact fixed-charge problem,
while `ExternalSphereBackend` provides an explicit common analytical dispatch
for *either* constraint. `Femm5ExternalSphereBackend` supports both through
one axisymmetric geometry/compiler path. It does not fallback to the exact
solution after a numerical failure.

## Independent Kelvin-image physics

For a sphere of radius `a`, external charge `q` at distance `d>a` along unit
axis `n`, with sphere's *prescribed* net charge `Q`, let
`k = 1/(4*pi*epsilon)` and define:

- Kelvin image `q' = -q*a/d` at `r' = a*a/d` along `n`, *inside the metal*.
- **Compensating central image `q0 = Q-q' = Q+q*a/d`** at the metal centre.
- The image charges sum to **Q**, the actual net charge on the isolated sphere.
- Exterior potential:
  `V(x) = k*[q/|x-xq| + q'/|x-x'| + q0/|x-center|]`.
- Uniform metal potential: `V_metal = k*q0/a`; inside metal `E=0`.
- Induced surface density:
  `sigma(theta) = -q*(d*d-a*a)/(4*pi*a*(d*d+a*a-2*d*a*cos(theta))**(3/2))
                   + q0/(4*pi*a*a)`.
  It integrates to Q, **not** to the grounded sphere's `-q*a/d`.
- Total sphere-on-source force along `n`:
  `F_n = k*q*[q'/(d-a*a/d)**2 + q0/d**2]`.
- Position-dependent interaction energy, relative to source at infinity:
  `U = k*q*Q/d - k*q*q*a/(2*(d*d-a*a)) + k*q*q*a/(2*d*d)`.
  The fixed sphere's own constant self-energy `Q**2/(2*C)` is omitted.
  Differentiating verifies `F_n = -dU/dd`.

The `q0` image is mathematical, **not another physical authored point charge**.
For `Q=0` the conductor is neutral but polarized: it can have negative sigma
near the positive source and positive sigma far away, and the force on an
external nonzero point charge remains attractive. Sufficient positive Q
can make a positive source experience net repulsion. The isolated sphere's
potential is generally **not zero even when Q=0**.

## Numerical FEMM 5

The existing `femm5_external.py` creates one grounded or fixed-net-charge
physical solid-sphere boundary, with **one** separate small FEMM charged
source sphere on the chosen axis. Only the physical sphere property changes:

- `Grounded()`: `ei_addconductorprop(name, 0, 0, 1)` = fixed 0 V.
- `FixedNetCharge(Q)`: `ei_addconductorprop(name, 0, Q, 0)` = fixed total Q.

FEMM independently calculates the solid sphere's potential and net charge,
external potential/field and near-surface local electric-field density.
The fixed total Q is an input constraint, so verifying FEMM reports Q alone
is **not** a sufficient physics test. Live validation must additionally
compare the *computed* metal voltage and exterior potential/field and sigma
profile against independently derived image-charge values, including the
neutral limit, positive/negative net Q, and mesh/domain/core-radius
sensitivity. The finite-core source is an approximation to an ideal point;
the outer Robin boundary approximates multipole decay on a finite domain.

Force and interaction energy are available **only from the exact analytical
reference** in this milestone. FEMM does **not** claim independent force
integration or moving-charge dynamics.

## Visual reuse

The M5 sampling and standalone HTML/JSON renderer are unchanged. The new
example stores four independently solved equilibria: grounded, isolated
neutral, isolated +2 nC, and isolated -0.6 nC, with identical external +1 nC
at d=0.27 m and sphere radius 0.12 m. All frames show actual conductor
charge and potential, field lines, equipotentials and an *outer-surface*
sigma profile. The slider changes between stored states; it does not simulate
continuous charge motion or solve FEMM in a browser.

```powershell
python examples/femm5_isolated_sphere.py --output output/isolated_sphere.html
Start-Process .\output\isolated_sphere.html
# After configuring FEMM_DIR and FEMM5_BINDING for FEMM 5:
python examples/femm5_isolated_sphere.py --backend femm --resolution 25 --output output/isolated_sphere_femm.html
python -m pytest tests/test_m8_live.py -vv -rA
```

## Acceptance and boundaries

The pure-Python tests cover charge conservation, exact equipotential boundary,
neutral induction, integrated sigma, `E=-grad(V)`, `F=-grad(U)`, strong-Q force
reversal, signed sources, 3D world-coordinate covariance, strict unsupported
cases, FEMM command construction/provenance and M5 viewer reuse. The separate
pinned real FEMM 5 workflow must run the new numerical tests alongside all
52 earlier live regressions; the Chromium workflow must exercise the new
HTML export. Results and tolerances will be recorded in [M8 acceptance](m8-acceptance.md)
**only after** live execution.

**Not supported in M8:** multiple external charges, an isolated sphere without
an external charge, external charge next to *spherical shells*, eccentric
spheres, arbitrary 3D numerical conductors, near-contact certified accuracy,
force measured directly by FEMM, particle motion, scene graph, or production
process supervision.
