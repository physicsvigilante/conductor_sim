# M24b — Composable linear drag and scheduled uniform electric fields

## One physical extension, several investigations

`DrivenModel` retains an existing immutable `PrescribedScenario` and adds two
explicit physical components: `LinearDrag` in a stationary medium and a named
`UniformFieldSchedule`. There is no oil-drop-specific solver. Each complete
phase is admitted by the existing field/plane/axis qualifier. Different questions
reuse the same model through `DrivenStudy`, M24a `PlaneEvent`, `VelocityReversal`
and `EventPolicy`. A new numerical investigation need not rebuild the apparatus.

The approved [charter](m24b_charter.md) was committed before implementation at
`4ba4c595e1a9772909c83fba1fa83e3ad832466c`; baseline main was
`96d93d4387901126a105f0d078314a7a83a33710`.

## Physical meanings

The full vector law is

    m dv/dt = q E_fixed(r) + q E_applied(t) + m g - b v,  b >= 0.

`b` is supplied in kg/s; no viscosity, fluid velocity, drag regime, particle
radius or Stokes coefficient is inferred. The medium is stationary in the
specified world frame. Drag is a separate velocity-dependent force, not an
imaginary electric field. The existing nonrelativistic limit and qualified
planar/axial domain still apply. A phase that breaks that domain is rejected,
even if an earlier phase was admissible. Existing singularity/discontinuity
clearance guards remain active.

The applied field is spatially uniform and piecewise constant, begins at t=0,
and has 1..32 explicit, strictly ordered phases. The convention is right
continuity at a phase boundary. Each reached switch retains both left and right
force/acceleration observations, with identical position, velocity and accumulated
work. Integration targets include the switch itself even when it lies between
requested display times. Trial stages on the incoming interval use the incoming
field; the next interval uses the new field. There is no velocity reset or impulse.

This is a prescribed-field approximation, not a Maxwell switching-field solve,
capacitor circuit transient, finite-disc fringe field or conductor-response model.
It excludes magnetic induction, radiation and propagation of the switch signal.

## Mechanical work ledger, not fictitious conservative energy

Four additional integration states retain

    W_fixed = integral q E_fixed dot v dt
    W_applied = integral q E_applied dot v dt
    W_gravity = integral m g dot v dt
    D = integral b |v|^2 dt >= 0

The reported numerical residual is

    K(t) - K(0) - W_fixed - W_applied - W_gravity + D.

D is physical dissipation, not numerical drift. Individual work contributions are
integrated along the same trajectory and checked with an explicit work tolerance.
Their cumulative sum is not forced to match K. No energy normalization or clipping
is used. Fixed-source and gravitational potential energies are available as
separate observations; the new result is not mislabelled as a conserved K+U record.

The ledger concerns the particle's mechanical work and dissipated energy, not
the complete battery/capacitor/medium energy budget. A step in an instantaneous
potential-energy reference is not mechanical work by an impulsive electric force.
An exactly balanced constant electric and gravitational force with positive b
causes exponential relaxation from a moving state, not finite-time arrest.
A speed below a numerical tolerance is not exact physical rest.

## Public Python authoring

```python
from conductor_sim import (
    PrescribedField, PointCharge, TestChargeMotionSpec, UniformGravity,
)
from conductor_sim.scenarios import PrescribedScenario
from conductor_sim.driven_motion import (
    LinearDrag, FieldPhase, UniformFieldSchedule, DrivenModel, DrivenStudy,
    EventPolicy, PlaneEvent, VelocityReversal, investigate_driven_motion,
)
from conductor_sim.driven_viewer import render_driven_run

base = PrescribedScenario(
    'lesson:base',
    TestChargeMotionSpec(
        PrescribedField(()), PointCharge(1e-9, (0., 0., .4)), 1e-9,
        (.4, 0., .15), duration_s=1.5, sample_interval_s=.1,
        plane_normal=(0., 1., 0.), gravity=UniformGravity((0., 0., -.2)),
    ), (), 'Teacher hypothetical: the original particle, launch and gravity.',
)
model = DrivenModel(
    base, LinearDrag(1e-9),
    UniformFieldSchedule((
        FieldPhase(0., (.2, 0., 0.)),
        FieldPhase(.37, (-1.2, 0., .5)),
    )), 'lesson:driven', 'Teacher-authored drag and scheduled applied field.',
)
questions = (
    VelocityReversal('turn:x', (1., 0., 0.), 'Horizontal reversal'),
    PlaneEvent('upper', (0., 0., .5), (0., 0., 1.), 'Detector', 1, True),
)
policy = EventPolicy(.02, 1e-9, 1e-10, 1e-9)
run = investigate_driven_motion(DrivenStudy(model, questions, policy))
other = investigate_driven_motion(DrivenStudy(model, questions[:1], policy))
assert run.study.model is other.study.model is model
html = render_driven_run(run)
```

An empty question tuple is allowed for a duration/work investigation. Work
absolute tolerance (joules) and relative tolerance are separate numerical
settings of `DrivenStudy`, not physical modifications. Output interval, ODE
error, work error, maximum event step and event localization tolerances have
different meanings.

Use `revise_driven_model(parent, model_id=..., note=..., drag=..., applied=...)`
to derive physical parameter variations. It returns the immutable child and a
record of its actual changes with the full parent retained. Source/component IDs
and kinds remain fixed; no-op changes are rejected. Genuine initial-state or mass
revisions use the existing `revise_scenario(..., motion_changes=...)`, supplied
as `base=` to `revise_driven_model`. Every resulting complete phase is requalified.
Structural component replacement and arbitrary new forces are not smuggled into
this parameter operation.

## Shared numerical execution and event limits

The existing adaptive vector RK4 loop is reused with a private typed adapter for
mechanical/work states. Old default requests still use the old six-component
state, record types and stepping policy. Driven states have the same first six
mechanical entries plus the four work entries. Position/velocity errors are never
computed using joules as velocity components. The opt-in work error criterion
and a maximum drag step of one quarter relaxation time bound the explicit method.
A stiff request can exhaust its declared step budget; it does not silently switch
physics, clamp velocity or report successful completion.

The M24a locator is reused, including fresh fractional RK states, source guards,
checked scalar proposals, direction filters, initial-state records and numerical
brackets. The whole extended state, including work, survives terminal localization.
Events within time tolerance of a scheduled change are marked event/switch-order
unresolved. A velocity merely touching zero at a switch is not fabricated as a
smooth reversal. A nonterminal unresolved question does not erase other resolved
observations; an unresolved terminal question conservatively truncates the run.

These are finite-resolution numerical procedures, not formal exact-ODE error
bounds, guaranteed all-root detection or material-contact times. Very close events,
grazing and numerical resolution failure may remain unresolved. Guards never
become impacts. No bounce, absorption, emission or charge transfer is supplied.
Events apply only to this prescribed-source particle family, not automatically to
conductor-induced motion or dipole rotation.

## JEE source and teacher additions

The official JEE Advanced 2020 Paper 2 Q3 text was reopened, and its checked-in
scanned counterpart, physical page 16 of `02_conductors_half_size.pdf`, was
rendered and inspected. The source supplies density 900 kg/m3, oil-drop radius
8e-7 m, disc spacing .01 m, voltage 200 V, g=10 m/s2, electron charge magnitude
1.6e-19 C, neglected buoyancy and final floating equilibrium after terminal fall.
It does not give b, the time of switching, a complete launch state or a unique
transient. The original question asks for the electron count, not the transient.

The source force-balance calculation gives a continuous charge magnitude about
9.651e-19 C, or 6.032 source-unit electron charges (integer answer approximately
6 with the supplied rounded data). `oil-hypothetical` deliberately uses the
continuous effective charge -mg/E for an exactly balanced classical demonstration.
It is **not** asserted to be an exact quantized charge or a unique original-exam
trajectory. The added relaxation time .002 s, terminal initial velocity -.02 m/s,
initial height .008 m and switch time .013 s are labelled teacher choices. Source
givens, derived equilibrium values and added inputs are separate in its JSON.
