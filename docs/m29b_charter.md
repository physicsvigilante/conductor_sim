# M29b — Frozen preimplementation charter: typed event observations across structurally distinct source inventories

**Standing owner direction:** develop continuously and merge routine milestones after validated exact-head CI and independent review PASS; interrupt for independent review, not redundant per-merge approval. This charter was written BEFORE M29b production code and is prospective: prior M29a/M28b records are unchanged.

## Educational need and existing-law reuse

M22a atomically assembles genuinely changed physical source memberships (add/remove/replace fixed sources, gravity membership) with stable identities and whole-model qualification. M29a independently integrates/comparisons genuine trajectories across such alternatives. M24a already offers physically qualified typed `PlaneEvent` and `VelocityReversal` observations with original native root brackets and source-guard truncation, while M28b applies such questions to M28a **parameter-only** revisions. A teacher should be able to ask exactly the SAME detector/reversal question across **different qualified source inventories**, without writing another force or root solver. This is a bounded composition gap, not a new Coulomb, induction, collision or unrestricted-3D model.

## Production contract

- Public `StructuralEventFamilyPlan` contains exactly one ordinary `StructuralFamilyPlan` (one immutable source-bound baseline, 1..5 independent typed M29a `StructuralCase` membership variations), a shared 1..16 tuple of built-in M24a `PlaneEvent`/`VelocityReversal` questions and one ordinary `EventPolicy`. Reuse `EventStudy` to reject baseline-invalid questions before any integration. Refuse arbitrary callbacks, duplicate event IDs or numerical policy passed as a source edit; never infer an event from plotted trajectory interpolation.
- Each structural child is **assembled directly from the unchanged original baseline**, once and atomically, by M22a `reassemble_scenario` (reuse M29a `_assembly`). Retained IDs and exact parent/child structural ledger/digest must reflect actual original fixed-source objects, replacement under new IDs and gravity membership. A structurally inadmissible child is recorded **rejected-structural-model** (no invented source inventory), without stopping unrelated siblings.
- Each whole-model-accepted child gets its OWN M24a `EventStudy` using the same questions/policy, then freshly integrates with unchanged `investigate_motion` and `validate_event_run`. A qualified whole model may separately **rejected-event-study** (e.g. initial on an ideal-stop surface whose acceleration changes side after source reassembly), **integration-failed** (recognized domain/numeric error), **complete** (M24a native `duration`) or **censored** (`source-guard`, `terminal-event`, `event-unresolved`). Original M24a termination, `outcomes`, `unresolved`, `ordering`, full numerical event-brackets and signed directions must be retained, not reduced to an invented yes/no.
- Reuse M28b's independently reviewed `_root_pair` **without copying/editing physics semantics**. A cross-scenario event shift is eligible ONLY when exactly one numerical root of the same authored event ID is `located` in BOTH **duration-complete** studies and signs agree. Opposite crossing directions, multiple roots, unlocated/unresolved/truncated events and even a single earlier root in a guard-terminated study are **unpaired** with explicit reason. Eligible shift reports BOTH original brackets, the difference of reported numerical root times, and conservative **numerical bracket-difference interval [child.lo−base.hi, child.hi−base.lo]**. These intervals do NOT bound error of the exact physical ODE or imply detector collision/impact.
- Use M28a's original `_shared_rows` only at **literally identical actual saved SI times** for full-world 3D position/velocity components and Euclidean distances; no interpolation, index alignment or after-guard samples. Distinguish independent structural alternatives from time evolution of source membership. Do not infer mechanical work from cross-inventory absolute potential energies or treat a material/transparent charged sphere as a conductor.
- `StructuralEventFamilyRun.as_dict()` is detached versioned finite JSON: baseline source/structural identity and native event history; each authored source edit, accepted `ScenarioReassembly` parent/child ledger (or explicit refusal), actual native event run (or refusal), original roots/brackets/outcomes/observed guard/terminal duration, per-ID eligible shift and only exact-time 3D differences. JSON is **not trusted import** and revision digest is not PDF/source authentication.
- Source-neutral, offline HTML **event-time chart and full table** is required. Each case explicitly lists source ID, authored name and built-in physical source type, gravity membership and actual M22a add/remove/replace ledger, plus native event outcome and original bracket/direction. A physical timeline line ends at its real last M24a solved time; numerical root markers use original saved times. Near-coincident overlapping terminal alternatives may be displayed with a grouped count marker **at the true stop boundary**; any decorative offset must be explicitly labeled NOT a physical event time and full individual root times remain readable in table and JSON. No event glyph may escape its physical scenario lane or the SVG. At 390px, source/observations table is readably **horizontally scrollable with a sticky scenario column** and no outer-page horizontal overflow; source text safely escaped, no browser ODE or external requests. Chart is an **event-time summary**, NOT apparatus geometry/particle path, and does not show conductor response or source changes during one trajectory.

## Frozen positive cards

P1 **Analytic uniform-E structural event shifts:** Baseline original `examples/m29a_structural_family.model("uniform-edits")`: q=+1nC, mass=1e-5kg, held E=(100,+50,0)V/m, v_x=.1m/s, T=.1s. All fully qualify and complete, each yields exactly one positive-signed detector root. Compare with independent quadratic `x=.1t + 0.5a_xt²`, `t = 2d/(v0+sqrt(v0²+2a_xd))`, and original numerical bracket shift intervals. Pure y/gravity changes preserve x crossing time to declared tolerance; x-field addition brings it earlier. Original source membership/IDs and all native event histories remain unchanged across sibling solves.
P2 **Guard with earlier real detector:** Original `model("guard-and-refusal")` (ballistic held zero E, q=+1nC, mass=1e-4kg, vx=1m/s, duration=.25s). Ask at x=.05m and far x=.22m. Far detector with this child is `search-truncated`, not proven absent. Another added distant positive point remains duration-complete with admissible comparisons; one off-plane source is structurally refused.
P3 **EventStudy-only structural refusal:** At launch x=0,v_x=0, baseline held E_x negative and positive q, terminal stop plane x=0 with normal +x and direction+1, baseline acceleration into allowed negative side. Adding enough +x E reverses initial acceleration at boundary so the physically admissible child is **rejected-event-study**, not structurally refused or silently simulated beyond authored stop. Another still-negative E child is admitted and duration-complete. Initial velocity, plane, event and numerical policy are unchanged.
P4 **Two crossings/multiple roots:** A held uniform retarding E_x and moving charge cross a passive detector twice during duration. Adding another held fixed uniform E source yields a second physically distinct duration-complete model with two original located roots sharing same event ID. Both original native root brackets preserved, but `_root_pair` returns **unpaired** rather than choosing arbitrary firsts.
P5 **Near-coincident signed terminal alternatives:** Two or up to 16 close ideal-stop planes retain all legal M24a overlapping terminal numerical candidates on the baseline and an independently reassembled uniform-source alternative. Every run censored at its original real terminal time, no across-censored event shift. HTML groups/counts same-lane alternatives without false after-stop motion; table and audit preserve each individual event/root bracket/sign. No wrong-lane glyph or clipped marker.
P6 **Unfamiliar qualified source structure and covariance:** A rotated 90° world arrangement with fixed signed point(s), symmetric off-plane mirror addition or rod/point sources and a signed detector yields the same numerical crossing times after rigidly rotating sources, particle launch/velocity and detector normal, within M24a finite-resolution tolerance. Independently checked initial force against direct Coulomb/rod quadrature or an analytical reference. No case-specific production law.
P7 **Actual offline Chromium:** Wide and 390px (source-neutral, no workbook attribution for unrelated cases), true original per-case source names/IDs/types, structural changes/gravity, numerical finite bracket, all native event roots, missing/censored/no-observation distinctions, source guard censoring, unobtrusive mobile scrolling and accessible source ID. Actual source status and time root in browser must match detached native output; no arbitrary external JSON accepted.

## Frozen negative cards

N1 Empty/overlong structural family, duplicate case IDs, malformed source changes/new identity collision, gravity membership conflict and unsupported source objects: reject at ordinary M29a boundaries or classify per-case without affecting unrelated siblings.
N2 Malformed shared event question tuple, unsupported arbitrary callback, duplicate question IDs, invalid/time-unresolvable EventPolicy or invalid baseline stop-side: reject before baseline integration.
N3 Whole-model valid but event-study-invalid child must be reported separately with actual accepted structural ledger, zero event samples; missing/rejected structural child has no invented source inventory.
N4 A run can have one located preguard root before a later source guard and STILL be unpaired. A terminal stop with many roots is also unpaired; opposite signs with a bidirectional detector are different physical questions. No comparison root beyond censored observation.
N5 No unqualified off-plane projection, fabricated 3D motion, numerical crossing by time-frame interpolation, post-guard path, SHA-as-PDF proof, unrestricted 3D, conductor contact or induction.
N6 Hostile source name/provenance printed inertly via text-only DOM/HTML escaping; 390px table remains truly usable and no page/network/console errors. Browser cannot silently drop event outcomes or entire nonmatching child.
N7 M22a structural authoring, M29a trajectory comparison, M28a property sweeps, M28b typed event numerical reference, M24a original event locator, M27b full-ring E/V and 97 real FEMM5 conductor regressions unchanged.
