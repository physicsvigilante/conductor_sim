# M12b — FEMM 5 finite-domain parallel-plate capacitor

## Authored physics and backend boundary

M12b introduces `Femm5ParallelPlateBackend` while reusing the accepted M12a
`ElectrostaticProblem`, `PointCharge`, two facing `ConductingPlane` components
and `Grounded`/`FixedPotential` boundary values. Nothing new is required in
the authored problem for a FEMM solve. The existing analytical
`ParallelPlateBackend` stays independent and supports fully 3D charges.

The FEMM 5 numerical geometry is **axisymmetric**, so every active point charge
must project onto the **same single footpoint** of the first plane. Multiple
active charges share the plane's normal line and use distinct **spherical
finite conductor source cores** with prescribed net charges. Charges at exactly
coincident 3D positions are grouped with compensated summation; canceled
sites do not create phantom cores. At most 16 grouped active source sites are
allowed. Any transverse source displacement, invalid plate geometry, reserved
conductor name, or insufficient finite-core clearance is rejected **before**
opening a FEMM session. No fake rings, no solver fallback.

## Finite FEMM boundary-value problem

Let the facing plates have separation `d`, potentials `V0,V1`, normal
`n` pointing from the first plate into the slab, and chosen symmetry-axis
footpoint `O`. A finite rectangular FEMM 2D meridian models

    0 <= r <= R,    0 <= z <= d,    R = d * outer_radius_factor

as a **3D cylinder** after axisymmetric revolution.

* `z=0` and `z=d`: each physical electrode is a separate fixed-potential
  FEMM conductor segment; `eo_getconductorproperties` supplies numerical
  potential and integrated charge, not image-solver values.
* `r=0`: rotation axis, with centered spherical source cores and real FEMM
  fixed-charge conductor properties. Each core charge is also read back
  independently.
* `r=R`: artificial **insulating side** (`D radial = 0`), achieved by
  leaving the FEMM segment's natural Neumann boundary condition unassigned.
  This is neither a conducting cylindrical wall nor an open Robin boundary.

This artificial side is explicitly important. It makes the charge-free
uniform capacitor solution **exact for this finite cylinder** while
constraining source-field radial flux at a finite R. The interior local
charge-induced fields converge toward the ideal infinite-plate solution as
R increases; no claim of a global guaranteed error is made. Meshing,
source core size, finite R and near-surface offset require sensitivity tests.

## Independent finite-disk charge identity

The cylinder has finite electrode disks of radius R, area A=pi*R^2, and
C = epsilon*A/d. Because the artificial side has zero normal D, the linear
harmonic weighting potentials are exactly z/d and 1-z/d even in this bounded
domain. For ideal point charges q_i at heights h_i, the **independent exact
finite-domain conductor charge identity** is

    Q_lower = C*(V0-V1) - sum_i(q_i*(1-h_i/d))
    Q_upper = C*(V1-V0) - sum_i(q_i*h_i/d)
    Q_lower + Q_upper = -sum_i q_i

These are identities for the specified insulated finite cylinder with ideal
points. FEMM's finite conductor source cores and mesh are numerical
approximations. The measured electrode Q values are validated against
these identities and numerical source Q individually; no result is copied
from these expressions into the FEMM solution.

Contrast with M12a: infinitely extended electrodes at *different potentials*
have infinite/unbounded total charge. M12a correctly reports `None` for
those ideal totals. FEMM reports **finite measured disk charges**, which
include both the uniform capacitor term `C*DeltaV` and source-induced
charges. Treating the two results as identical would be a physics error.

## Field, density and viewer

FEMM provides independently sampled potential `V` and field components
`Er,Ez`, mapped into authored 3D world coordinates. Source-core interiors
are excluded; physical plate surfaces have one-sided E discontinuities.
Local `sigma = epsilon*(E_vacuum dot n_face)` is approximated using FEMM
field samples just inside the gap, never substituted from the analytical
image series. Values depend on mesh and sample offset.

The existing slice/viewer handles both plate halfspaces, two density profiles,
and charge-state playback. A new `CylindricalDomain` and
`CylinderSideBoundary` mask and terminate traces at r=R, rather than
incorrectly applying the spherical FEMM-domain mask from M11.

```bash
# Works without FEMM: analytical preview.
python examples/parallel_plates.py --output output/m12-analytic.html

# Requires actual FEMM 5 headless solver/binding.
python examples/parallel_plates.py --backend femm --resolution 21 --output output/m12-femm.html
```

## Acceptance gates and remaining limitations

M12b introduces fake-client command-contract tests and real pinned FEMM 5
integration tests for source-free bias, single-charge induction, independent
positive/negative cores, zero-total-charge signed dipoles, orientation
covariance, Q/flux and V/E/sigma against the independent M12a reference,
outer-radius/mesh/core sensitivity, pre-session refusal, and a real FEMM
multi-state HTML export.

The real-FEMM workflow must pass **all retained M1–M11 numerical tests plus
the new M12b suite with zero skips**. Standard Python 3.10/3.12 and browser
checks remain separate. The two-plate simulation is *not* finite separated
metal slabs with fringing fields, arbitrary off-axis 3D FEMM, connected
electrodes, or exact force/energy dynamics. FEMM process isolation is not
production-grade. Do not merge on green fake-client tests alone.
