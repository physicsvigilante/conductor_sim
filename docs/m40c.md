This milestone reuses the actual M40a qualified 3D spherical cavity model, strict source containment, M39a Gauss ledger and M40b true 3D-to-XY geometry projection. The teacher changes exactly **one existing named charge's authored static position** inside the very same sphere; no charge amount, source identity, cavity assignment, sphere, material or electrical constraint is altered. The baseline model is immutable. Before and after are *separate hypothetical equilibria*; no physical movement trajectory, elapsed time, force/work/energy, current or transient grounding is calculated.

Run from the source checkout with the applicable test dependencies available:

```sh
python -m pytest tests/test_m40c_static_relocation.py -q
python -m tools.m40c_static_example --output-dir output/m40c
python -m tools.m40c_static_reference --input output/m40c/m40c-static-teacher.json --output output/m40c/m40c-independent-witness.json
```

Open `output/m40c/m40c-static-teacher.html` locally. There is **no JavaScript or network access**, just two real-world XY orthographic projections at the same scale, explicit original and revised XYZ source positions and a signed numerical table for six actual spherical point rays per cavity (up to 24 admitted). The normals are the *original raw binary64 ray inputs*, not rounded display normals. Each density is recomputed by the unchanged native M40a qualified solver. Whole-face Q remains the actual Gauss total (never a sparse atlas sum); isolated/grounded electrical constraints require independent static model pairs, not a current timeline.

`StaticSigmaComparison.as_dict()` records M40a v2 original/revised witnesses per face, with signed `C/m^2`, stable source ID and full before/after geometry. A relocation instruction carries its requalified baseline, including the electrical constraint. The comparison checks the total-density change against the moved charge’s contribution at the same raw ray, since every other charge stays fixed. The detached verifier obtains that contribution from the real-plus-Kelvin-image field. Differences too small or inconsistent for a robust binary64 subtraction are labeled **unresolved numerical difference**, not falsely interpreted as theorem zeros. A truly untouched cavity is certified unchanged. The standalone checker uses the pre-existing independent **real + Kelvin image normal electric-field** reference to verify every signed baseline/revised source record and independently checks exact-one-source identity/position change, whole Gauss charges, original raw rays and all viewer measurements. This is internal evidence consistency only, **not** cryptographic authentication of arbitrary self-consistent downloaded JSON or edited HTML.
