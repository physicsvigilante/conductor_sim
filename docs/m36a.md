```sh

python -m pytest tests/test_m36a_jee30_audit.py -q
```

The Python tool is deliberately **standard-library only**, checks original case IDs/page/question provenance against the unchanged M21a matrix, validates the extra official-source apparatus, route counts, existing documentation links and no fabricated physical/educational passes, then emits separate denominators.
